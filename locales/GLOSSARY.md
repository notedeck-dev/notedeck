- 固有名詞 (NoteDeck / Misskey / フォーク名 / AiScript / MisStore / HEARTBEAT) は訳さない

## 表記の規則

画面ごとに書き方がばらけていた (#704) ので揃えた。`tests/lint/i18nStyle.test.ts` が正本 (ja-JP.yml) を検査する。規則を変えるときはこの表と lint を一緒に直す。

| 項目 | 書き方 | 例 | 理由 |
|---|---|---|---|
| 英数字と和文の間 | 半角空白を入れる | Web UI で開く / 1 行に 1 つ / {count} 件 | NoteDeck の多数派。英字の多い IDE 系の文言が読みやすい。本家は空白なし (2026-09-26 に決定) |
| 括弧 | 半角 `()`、前に空白 | 保存に失敗しました (E401) | 本家も半角が多数 |
| 疑問符・感嘆符 | 和文の後は全角 `？` `！` | 削除しますか？ | 本家と同じ |
| 三点リーダー | `...` | 読み込み中... | 本家と同じ |
| 句点の後 | 空白を入れない | 〜します。次に〜 | |
| カタカナ語の語尾 | 長音をつける | ヘッダー / フィルター / パラメーター / エディター / ブラウザー / プロバイダー / セレクター / ビューアー / プレースホルダー | JIS・マイクロソフトの表記規則。本家はフィルタ・パラメータと短い形が多い (2026-09-26 に決定) |
| 切り替え | 切り替え (「切替」と書かない) | ダークモードに切り替え | 本家と同じ |
| 読み込み / リロード | 読み込み・リロード (「読込」「再読み込み」と書かない) | 読み込み済み / リロード | 本家と同じ |
| 取り消し | 取り消し・取り消す (「取消」と書かない) | 予約を取り消す | 本家と同じ |
| デフォルト | デフォルト (「既定」「default」と書かない) | デフォルトに戻す | 本家と同じ |
| 送り仮名 | 済み (「済」と書かない) | インストール済み | |
| 確認の問いかけ | 〜しますか？ (「本当に〜？」と書かない) | リセットしますか？ | 確認 UX の二重パラダイムの解消 (#704) |
| 元に戻せない操作の注記 | この操作は取り消せません。 | 〜を削除しますか？この操作は取り消せません。 | 注記の不統一の解消 (#704) |
| 確認の取り消しボタン | キャンセル (「やめる」と書かない) | キャンセル | 本家と同じ (2026-09-26 に決定) |
| 失敗の知らせ | 〜に失敗しました (「〜失敗」「〜失敗:」と書かない)。コードは `({code})`、詳細は `: {error}` | 保存に失敗しました: {error} | 状態を表す名詞 (「失敗」「連続失敗」) は対象外 |
| 解除の見出し | ボタン・メニューは名詞形 (ミュート解除 / ブロック解除 / フォロー解除)、文は「〜を解除しました」 | ミュート解除 | 助詞ゆれの解消 (#704) |

## 共通語 (`_common`)

複数の画面で同じ意味の語は `_common` に置く。ja と en の**両方**が同じ値のときだけ寄せる (「無効」は Disabled と Invalid で意味が違うので `disabled` と `invalid` に分かれている)。
