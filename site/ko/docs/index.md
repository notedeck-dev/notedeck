# NoteDeck이란

NoteDeck은 Misskey를 **덱**으로 쓰기 위한 데스크톱 / 모바일 앱입니다. 타임라인, 알림, 검색, 채팅 등을 세로로 긴 칼럼으로 만들어 가로로 나란히 놓고, 여러 계정과 서버를 한 화면에서 다룰 수 있습니다.

브라우저로 여는 Misskey 웹 UI와는 다음 점이 다릅니다.

- **계정을 넘나들며 배치할 수 있습니다** — 칼럼마다 다른 계정을 지정하거나, 모든 계정의 알림을 칼럼 하나에 모을 수 있습니다
- **흘러간 노트가 손안에 남습니다** — 표시한 노트는 로컬 데이터베이스에 쌓이고, 나중에 전문 검색으로 찾을 수 있습니다
- **OS의 기능을 쓸 수 있습니다** — 글로벌 단축키, 네이티브 알림, 시스템 트레이, 별도 창으로 분리하기

::: info 앱은 아직 한국어를 지원하지 않습니다
앱 화면은 현재 일본어와 영어로만 제공됩니다 (번역은 [#135](https://github.com/notedeck-dev/notedeck/issues/135)에서 진행 중입니다). 기본적으로 OS 언어를 따르며, '외관 (Appearance / アピアランス)' → '언어 (Language / 表示言語)'에서 바꿀 수 있습니다. 이 문서에서는 화면에서 찾을 수 있도록 버튼과 메뉴 이름 옆에 일본어 표기를 함께 적습니다.
:::

## 세 가지 기본 개념

이 세 가지만 알면 NoteDeck의 화면을 읽을 수 있습니다.

| 개념 | 무엇인가 | 사라지는가 |
|---|---|---|
| **칼럼** | 계속 흘러가는 것을 두는 세로로 긴 영역. 타임라인, 알림, 채팅, AI 등 | 저장됩니다. 앱을 다시 시작해도 남습니다 |
| **창** | 잠시 여는 작은 창. 노트 상세, 프로필, 설정, 에디터 등 | 닫으면 사라집니다. 저장되지 않습니다 |
| **프로파일** | 칼럼 배치를 통째로 저장한 것. 용도별로 전환합니다 | 저장됩니다 |

"계속 흘러가는 것은 칼럼, 지금만 보고 싶은 것은 창"이라는 구분입니다. 자세한 내용은 [칼럼과 창](/ko/docs/deck/columns)을 참고하세요.

## "IDE"라고 부르는 이유

NoteDeck은 스스로를 Integrated Deck Environment (통합 덱 환경)라고 부릅니다. 에디터가 "텍스트를 쓰는 곳"에 머무르지 않고 디버거와 터미널을 내장하듯, NoteDeck도 Misskey를 "읽고 쓰기"만 하는 도구로 두지 않습니다.

- 서버와 주고받는 내용을 그대로 들여다보는 [인스펙터](/ko/docs/deck/columns#도구-칼럼)
- [스토어](/ko/docs/guide/store)에서 설치하는 플러그인, 테마, 위젯
- 직접 쓴 처리를 명령으로 추가할 수 있는 AiScript
- [AI](/ko/docs/guide/ai)를 파트너로 상주시키는 구조

쓰지 않아도 평범한 클라이언트로 충분히 쓸 수 있지만, 깊이 들어갈수록 나만의 도구가 됩니다.
