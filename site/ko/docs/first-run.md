# 처음 설정하기

처음 실행하면 아직 계정이 없는 상태에서 튜토리얼이 시작됩니다. 안내를 따라가면 로그인부터 알림 확인까지 끝납니다.

도중에 그만둬도 그때까지 설정한 내용은 남습니다. 나중에 설정 메뉴 맨 앞의 [**튜토리얼**](#튜토리얼-다시-하기) (チュートリアル)에서 이어서 할 수 있습니다.

## 1. 계정 추가하기

계정 추가 창에서 Misskey 서버의 호스트 이름 (예: `misskey.io`)을 입력하고 인증합니다. 브라우저가 열려 서버 쪽 인증 화면으로 이동하며, 허용한 뒤 NoteDeck으로 돌아와 "**인증했습니다**" (認証しました)를 누릅니다. 실패했다면 "다시 하기" (やり直す)로 처음부터 시작합니다.

로그인 정보 (액세스 토큰)는 OS 키체인에 보관됩니다.

- macOS → 키체인 접근
- Windows → 자격 증명 관리자
- Linux → Secret Service (GNOME Keyring 등. 없는 환경에서는 암호화 파일로 대피)
- Android → Android Keystore

앱의 설정 파일 안에 토큰을 평문으로 두는 일은 없습니다.

::: tip 여러 계정
같은 절차를 반복하면 다른 서버의 계정도 추가할 수 있습니다. 몇 개를 넣어도 괜찮습니다. 칼럼마다 어느 계정으로 동작할지 고를 수 있습니다.
:::

## 2. 덱을 내 것으로 만들기

NoteDeck은 칼럼을 나란히 놓고 씁니다. 처음에는 홈 타임라인과 멘션이 놓인 상태로 시작하며, 둘 다 "모든 계정" (全アカウント) — 추가한 모든 계정을 한꺼번에 표시하는 칼럼입니다. 계정을 늘릴수록 같은 칼럼에 여러 서버의 흐름이 합쳐집니다.

놓여 있는 칼럼은 그대로 써도, 지워도 됩니다. 칼럼 헤더에서 순서 변경, 너비 변경, 삭제를 할 수 있고, "칼럼 추가" (カラム追加, ＋)에서 알림, 검색, 채팅 등 필요한 칼럼을 더해 갑니다. 무엇을 어디에 둘 수 있는지는 [칼럼과 창](/ko/docs/deck/columns)을 참고하세요.

모두 지워 버려도 빈 덱에 나타나는 "기본 구성으로 시작" (デフォルトの構成で始める)으로 처음 배치로 되돌릴 수 있습니다.

## 3. (선택) AI 연결하기

여기부터는 첫 튜토리얼의 바깥입니다. AI 기능을 쓰려면 자신의 API 키를 등록합니다. 쓰지 않아도 다른 기능은 모두 동작합니다.

1. 설정 메뉴의 **연결** (接続)에서 Anthropic / OpenAI 등 프로바이더의 API 키를 등록합니다
2. 설정 메뉴의 **에이전트** (エージェント)에서 등록한 연결을 AI 프로바이더로 고릅니다
3. 내비게이션 바의 "더 보기" (もっと)에서 AI 칼럼을 엽니다 (내비게이션 바에 AI 버튼을 놓을 수도 있습니다)

API 키는 OS 키체인에 보관되며, 설정 파일에는 쓰이지 않습니다. 자세한 내용은 [AI와 함께 쓰기](/ko/docs/guide/ai)를 참고하세요.

## 튜토리얼 다시 하기

설정 메뉴 맨 앞에 있는 **튜토리얼** (チュートリアル)을 열면 카테고리별 체크리스트가 나옵니다. 각 항목은 "시작" (はじめる), "이어서" (続きから), "다시 한번" (もう一度)으로 진행할 수 있으며, 이미 끝낸 것은 그대로 남습니다. "확장 만들기" (拡張をつくる) 카테고리는 [개발자 모드](/ko/docs/#개발자-모드)에서 열립니다.
