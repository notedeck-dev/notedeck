# 처음 설정하기

처음 실행하면 아직 계정이 없는 상태에서 튜토리얼이 시작됩니다. 안내를 따라가면 로그인부터 덱 정리까지 끝납니다.

도중에 그만둬도 그때까지 설정한 내용은 남습니다. 나중에 [About 창](#튜토리얼-다시-하기)의 "튜토리얼 보기" (チュートリアルを見る)로 이어서 할 수 있습니다.

## 1. 계정 추가하기

로그인 창에서 Misskey 서버의 호스트 이름 (예: `misskey.io`)을 입력하고 인증합니다. 브라우저가 열려 서버 쪽 인증 화면으로 이동하며, 허용하면 NoteDeck으로 돌아옵니다.

로그인 정보 (액세스 토큰)는 OS 키체인에 보관됩니다.

- macOS → 키체인 접근
- Windows → 자격 증명 관리자
- Linux → Secret Service (GNOME Keyring 등)

앱의 설정 파일 안에 토큰을 평문으로 두는 일은 없습니다.

::: tip 여러 계정
같은 절차를 반복하면 다른 서버의 계정도 추가할 수 있습니다. 몇 개를 넣어도 괜찮습니다. 칼럼마다 어느 계정으로 동작할지 고를 수 있습니다.
:::

## 2. 덱을 내 것으로 만들기

NoteDeck은 칼럼을 나란히 놓고 씁니다. 처음에는 칼럼이 이미 놓인 상태로 시작하며, 모두 "모든 계정" (全アカウント) — 추가한 모든 계정을 한꺼번에 표시하는 칼럼입니다. 계정을 늘릴수록 같은 칼럼에 여러 서버의 흐름이 합쳐집니다.

놓여 있는 칼럼은 그대로 써도, 지워도 됩니다. 칼럼 헤더에서 순서 변경, 너비 변경, 삭제를 할 수 있고, "칼럼 추가" (カラム追加, ＋)에서 알림, 검색, 채팅 등 필요한 칼럼을 더해 갑니다. 무엇을 어디에 둘 수 있는지는 [칼럼과 창](/ko/docs/deck/columns)을 참고하세요.

모두 지워 버려도 빈 덱에 나타나는 "기본 구성으로 시작" (既定の構成で始める)으로 처음 배치로 되돌릴 수 있습니다.

## 3. (선택) AI 연결하기

AI 기능을 쓰려면 자신의 API 키를 등록합니다. 쓰지 않아도 다른 기능은 모두 동작합니다.

1. 연결 관리 창에서 Anthropic / OpenAI 등 프로바이더의 API 키를 등록합니다
2. AI 설정에서 등록한 연결을 AI 프로바이더로 고릅니다
3. 사이드바의 AI 버튼에서 AI 칼럼을 엽니다

API 키는 OS 키체인에 보관되며, 설정 파일에는 쓰이지 않습니다. 자세한 내용은 [AI와 함께 쓰기](/ko/docs/guide/ai)를 참고하세요.

## 튜토리얼 다시 하기

언제든지 처음부터 다시 할 수 있습니다. **About 창**을 열고 "튜토리얼 보기" (チュートリアルを見る)를 고르세요. 이미 끝낸 단계는 자동으로 건너뜁니다.
