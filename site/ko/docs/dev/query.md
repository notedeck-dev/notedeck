# 칼럼 쿼리

칼럼 쿼리는 칼럼에 흘러오는 노트를 걸러 내기 위한 식입니다. AiScript의 부분 집합으로 쓰며, **true를 반환한 노트가 표시됩니다**. "○○ 숨기기"를 쓸 때는 조건을 쓴 다음 전체를 `!(...)`로 감쌉니다.

```is
/// @ 1.2.1
// 특정 키워드를 포함한 노트를 숨기기 — true = 표시
!(note.text != null && note.text.lower().incl("스포일러"))
```

쿼리의 정의, 편집, 스토어에서의 설치는 "쿼리" (クエリ) 칼럼에서 하고, 어느 칼럼에 적용할지는 각 칼럼의 필터 메뉴 토글로 전환합니다. 타임라인 외에 [클라이언트 검색](/ko/docs/guide/search#클라이언트-검색-칼럼)의 결과에도 적용할 수 있습니다. 여러 쿼리는 And로 합성되므로, 쿼리 하나에는 기능 하나만 맡기는 편이 다루기 쉽습니다.

## 참조할 수 있는 것

식 안에서 자유롭게 참조할 수 있는 것은 `note`뿐입니다. 다음 필드는 빠르게 평가되며, 로컬에 쌓인 노트 검색에도 쓸 수 있습니다.

```
note.text  note.cw  note.visibility  note.localOnly
note.renoteId  note.replyId
note.user.username  note.user.host  note.user.name
note.files.len  note.reactions["이모지_이름"]
```

비교와 논리 연산, 문자열의 `incl` / `starts_with` / `ends_with` / `lower` / `upper`, 배열의 `incl` / `len`, `let`, 재귀하지 않는 순수 함수를 쓸 수 있습니다.

이 범위를 벗어나는 필드 (`note.user.isCat`, `note.channelId`, `note.renote.text`, `note.poll` 등)도 동작하지만, 한 건씩 평가하는 느린 경로로 떨어집니다. 결과는 같고 속도만 다릅니다. 어느 경로로 동작하고 있는지는 쿼리 칼럼의 ⚡ / 🐢 배지로 알 수 있습니다 (⚠는 해석할 수 없는 부분이 있는 것).

## 쓸 때의 주의점

- **null은 `&&`의 단락 평가로 피합니다** — `note.text` / `note.cw` / `note.user.name`은 null일 수 있습니다. `note.text != null && note.text.incl("x")` 형태로 씁니다. `let`은 먼저 평가되므로 가드가 되지 않습니다
- **이항 연산자 뒤에서 줄을 바꾸지 않습니다** — 식은 한 줄에 담거나 함수로 분리합니다
- **외부와 통신할 수 없습니다** — `Mk:api`나 현재 시각 가져오기, 비동기 처리는 저장할 때 거부됩니다
- **해시태그 전용 필드는 없습니다** — 본문의 문자열 일치로 대신합니다. 앞부분 일치로 의도하지 않은 태그에도 걸릴 수 있다는 점에 주의하세요
- **칼럼 설정에 이미 있는 것은 만들지 않습니다** — 리노트 제외, 답글 제외, 미디어만 등은 칼럼의 필터 메뉴에 토글로 준비되어 있습니다 (나오는 토글은 타임라인의 종류와 서버에 따라 다릅니다)

## 동작하지 않게 되었을 때

- 쿼리 본체를 비활성화하면, 적용하고 있는 칼럼에서는 "없는 것"으로 다뤄집니다
- 평가에 시간이 너무 오래 걸리는 쿼리는 자동으로 멈춥니다. 쿼리 칼럼에서 "재개" (再開)할 수 있습니다
- 참조 대상이 사라졌거나 해석할 수 없는 경우에는 해당 노트를 표시하지 않는 쪽으로 처리합니다. 세이프 모드 중에는 쿼리 자체를 멈추고 모두 표시합니다
- 편집에는 이력이 남아 이전 버전으로 되돌릴 수 있습니다

## 저장 위치

설정 폴더의 `queries/`에 식 `<slug>.is`와 메타 정보 `<slug>.meta.json5` 두 파일로 저장됩니다. 다른 배포물과 마찬가지로 모든 계정용과 계정별 풀로 관리합니다.

## 설치하기와 배포하기

[스토어](/ko/docs/guide/store)에서 설치한 쿼리를 그대로 쓸 수도, 편집해서 자기에게 맞게 고칠 수도 있습니다. 설치만 해서는 어느 칼럼에도 적용되지 않으므로, 쓸 칼럼의 필터 메뉴에서 활성화하세요. 스토어 쪽에서 업데이트되면 차이점과 함께 알려 줍니다. 새로 만들기와 편집의 입구는 [개발자 모드](/ko/docs/#개발자-모드)에서 열립니다. 만든 것은 [MisStore](https://store.notedeck.io)에서 배포할 수 있습니다 ([제출 방법](https://github.com/notedeck-dev/misstore/blob/main/CONTRIBUTING.md) / [형식](https://github.com/notedeck-dev/misstore/blob/main/docs/registry-format.md#クエリ)).
