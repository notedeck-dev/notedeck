# 백업

## 무엇을 지키고 싶은가

NoteDeck이 가진 데이터는 두 가지로 나뉩니다.

| | 내용 | 위치 |
|---|---|---|
| **설정** | 칼럼 구성, 테마, 키 바인딩, 플러그인, 메모 등 | [설정 폴더](/ko/docs/config/files#설정은-어디에-있나) |
| **노트 캐시** | 흘러온 노트의 축적, 계정 정보 | `notecli.db` |

## 설정 백업

설정은 내보내기 / 가져오기를 지원합니다. 내보낸 파일을 다른 컴퓨터에서 불러오면 같은 환경을 재현할 수 있습니다.

대상은 [설정 파일](/ko/docs/config/files#무엇이-어디에-쓰이나)에 나열한 파일과 폴더입니다. **API 키와 액세스 토큰은 포함되지 않습니다** (OS 키체인에 있기 때문입니다). 옮겨 간 곳에서는 다시 로그인해야 합니다.

## 노트 백업

`notecli.db`를 **복사하기만 하면** 됩니다. SQLite 파일이므로, 그 하나에 쌓아 둔 노트도 계정 정보도 통째로 들어 있습니다.

앱을 종료한 뒤에 복사하세요. 실행 중에 복사하면 쓰기 도중의 상태를 잡을 수 있습니다.

::: warning 지우면 되돌릴 수 없습니다
앱을 제거해도 설정과 캐시는 남지만, 설정 폴더를 통째로 삭제하면 쌓아 둔 노트도 사라집니다. 서버에서 다시 가져올 수 있는 것은 서버에 아직 남아 있는 것뿐입니다.
:::

## Misskey 쪽 데이터

내 게시물, 팔로우, 즐겨찾기처럼 서버에 맡겨 둔 데이터의 백업은 Misskey 쪽 기능입니다. 서버의 설정 화면에서 내보내세요. NoteDeck의 백업은 어디까지나 "이 기기의 상태"를 저장하는 것입니다.
