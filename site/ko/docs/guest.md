# 로그인 없이 써 보기

회원 가입도 이메일 주소도 없이 서버의 공개 콘텐츠를 둘러볼 수 있습니다. 먼저 사용감을 확인하고 싶을 때나, 로그인하지 않고 다른 서버를 들여다보고 싶을 때 쓰세요.

## 게스트 추가하기

로그인 창에서 서버의 호스트 이름을 입력한 뒤 "**게스트로 열람**" (ゲストとして閲覧)을 고릅니다. 인증은 일어나지 않으며, 그 서버의 공개 API만 쓰는 계정으로 추가됩니다.

여러 서버의 게스트를 동시에 가질 수 있습니다. 로그인한 계정과 섞어 써도 괜찮습니다.

## 할 수 있는 것과 할 수 없는 것

::: tip 할 수 있는 것

- 공개 타임라인 (로컬, 글로벌 등) 열람
- 채널, 갤러리, 페이지 등 공개 콘텐츠 열람
- 서버 정보, 커스텀 이모지, 연합 차트 살펴보기
- 테마, 위젯 등 로컬 도구

:::

::: warning 할 수 없는 것

- 게시, 리액션, 팔로우
- 알림 수신
- 드라이브, 리스트, 안테나, 클립 관리

:::

쓸 수 없는 칼럼은 "칼럼 추가" (カラム追加) 목록에 그 사실이 표시되며 고를 수 없습니다.

볼 수 있는 범위는 각 서버의 공개 설정에 달려 있습니다. 로그인하지 않은 사용자에게 아무것도 보여 주지 않도록 설정한 서버에서는 게스트로는 아무것도 표시되지 않습니다.

## 그만둘 때

게스트 계정을 삭제하기만 하면 됩니다. 계정 메뉴에서 "**게스트 삭제**" (ゲストを削除)를 고르세요. 서버 쪽에는 아무것도 남지 않습니다.

그대로 정식으로 로그인하고 싶어지면 평소처럼 [계정을 추가](/ko/docs/first-run#_1-계정-추가하기)하세요. 게스트와 로그인한 계정은 따로 취급되므로, 게스트를 지운 뒤 다시 넣을 필요는 없습니다.
