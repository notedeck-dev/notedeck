# 키보드 조작

마우스 없이 조작할 수 있도록 만드는 것을 목표로 하고 있습니다. 헷갈리면 **명령 팔레트**를 여세요.

## 명령 팔레트

`Ctrl+K` (텍스트를 입력하는 중이 아니라면 `/`나 `?`도 가능)로 엽니다. 칼럼 추가, 계정 전환, 설정 열기, 게시하기 — 주요 조작은 여기서 이름으로 찾아 실행할 수 있습니다.

플러그인이나 직접 쓴 AiScript의 명령도 같은 팔레트에 나타납니다.

## 주요 단축키

키는 두 종류로 나뉩니다. **보조 키 조합**은 앱 안 어디서든 동작하고, **단일 키**는 텍스트 입력 중에는 동작하지 않습니다 (입력을 방해하지 않기 위해서입니다).

| 조작 | 보조 키 조합 | 단일 키 |
|---|---|---|
| 명령 팔레트 | `Ctrl+K` | `/` `?` |
| 검색 | `Ctrl+Shift+F` | `s` |
| 알림 | — | `i` |
| 게시하기 | `Ctrl+Shift+N` | `p` `n` |
| 칼럼 추가 | `Ctrl+Shift+A` | — |
| 칼럼 닫기 | `Ctrl+W` | — |
| 칼럼 고르기 | `Ctrl+1`~`Ctrl+9` | `Shift+H` / `Shift+L`로 좌우 |
| 프로파일 전환 | `Alt+1`~`Alt+9` | `g`로 메뉴 |
| 노트 위아래로 이동 | — | `j` / `k` |
| 노트에 답글 / 리액션 / 리노트 | — | `r` / `e` / `q` |
| 사이드바 열기/닫기 | `Ctrl+\` | — |
| 설정 / 튜토리얼 | `Ctrl+,` / `F1` | — |
| 화면 확대 / 축소 / 초기화 | `Ctrl++` / `Ctrl+-` / `Ctrl+0` | — |
| Boss Key (창 숨기기) | `Ctrl+Shift+B` | — |
| 퀵 노트 (어디서든 게시) | `Ctrl+Alt+N` | — |

`Ctrl+Shift+B` (Boss Key)와 `Ctrl+Alt+N` (퀵 노트)은 **OS 전체 단축키**입니다. NoteDeck이 뒤로 가 있어도, 다른 앱을 쓰는 중에도 동작합니다.

## 직접 지정하기

키 바인딩은 모두 바꿀 수 있습니다. VS Code의 `keybindings.json`과 같은 발상으로, 기본 할당을 사용자 쪽에서 덮어쓰는 방식입니다. 설정은 `keybinds.json5`에 저장됩니다.

각 단축키에는 적용 범위 (스코프)가 있습니다.

- `global` — 앱 안에서 항상 유효합니다. 보조 키 조합에 씁니다
- `body` — 텍스트 입력 중에는 무효입니다. 단일 키에 씁니다
- `os-global` — OS 전체에서 유효합니다 (데스크톱만, 보조 키 필수). 키 바인딩 설정의 "OS 전체" (OS 全体) 토글로 어느 명령에든 지정할 수 있습니다

단일 키를 `global`로 하면 그 글자를 입력할 수 없게 되므로, 보조 키가 없는 키에는 `body`를 지정하세요.

파일 위치와 편집 방법은 [설정 파일](/ko/docs/config/files)을 참고하세요.
