# AI와 함께 쓰기

NoteDeck에는 AI를 넣을 수 있지만, **사용 여부는 선택 사항**입니다. 자신의 API 키를 연결했을 때만 활성화되며, 연결하지 않아도 다른 기능은 모두 쓸 수 있습니다.

앱 쪽에서 AI 이용료를 대신 부담하는 구조는 없습니다. 요금은 계약한 프로바이더가 직접 청구합니다.

## 연결하기

1. 연결 관리 창에서 프로바이더의 API 키를 등록합니다
2. AI 설정에서 등록한 연결을 고릅니다

Anthropic, OpenAI, xAI, Google, OpenRouter, OpenCode Go는 템플릿이 내장되어 있어, 골라서 API 키를 붙여 넣기만 하면 연결됩니다.

지원하는 형식은 **Anthropic Messages 호환**과 **OpenAI Chat Completions 호환** 두 가지입니다. 템플릿에 없는 서비스라도, 직접 운영하는 LLM 게이트웨이 등 둘 중 하나의 형식을 쓴다면 직접 등록해서 연결할 수 있습니다.

API 키는 OS 키체인에 보관됩니다. 설정 파일에는 쓰이지 않으며, 플러그인이나 AI 자신도 그 내용을 읽을 수 없습니다.

## 할 수 있는 것

AI 칼럼에서 대화하는 것 외에도, 노트 메뉴에서 바로 AI에게 넘길 수 있습니다 (요약하기, 번역하기 등).

AI는 앱 조작도 할 수 있습니다. 칼럼 추가, 계정 전환, 테마 만들기, 키 바인딩 변경 — 대화 중에 부탁하면 됩니다. AI가 조작한 곳은 화면에서 빛나므로 무슨 일이 일어났는지 알 수 있습니다.

게시, 리액션 등 **외부에 영향을 주는 조작 전에는 반드시 확인 대화 상자가 나옵니다**. 멋대로 게시되는 일은 없습니다.

## 무엇을 보여 줄지 정하기

AI에게 넘기는 정보는 설정에서 고를 수 있습니다.

- 지금 쓰고 있는 계정
- 열려 있는 칼럼
- 화면에 보이는 노트
- 대화 기록

필요 없는 것은 꺼 둘 수 있습니다.

메모는 항상 넘기지는 않습니다. AI가 이어 가는 기억은 "비망록" (아래 참고)에 있으며, 개별 메모는 필요할 때 AI가 검색해서 읽습니다.

## 인격과 기억

AI에는 캐릭터를 바꿔도 변하지 않는 **인격**과 두 종류의 기억이 있습니다. AI 설정의 "AI의 인격과 기억" (AI の人格と記憶)에서 언제든 읽을 수 있고, 줄마다 고치거나 지울 수 있습니다.

- **인격**: 가치관과 경계, 말투의 핵심. AI는 스스로 고쳐 쓰지 않고, 제안한 뒤 승인을 기다립니다
- **당신에 대해 기억하는 것**: 호칭이나 말투 취향 등 대화에서 당신이 전한 것. "나에 대해 기억하기"를 끄면 넘기지 않고, 새로 기억하지도 않습니다 ("모두 잊기"는 별도의 조작입니다)
- **비망록**: AI 자신이 주워 담은 작은 사실이나 정한 것

처음 AI 칼럼을 열 때는 "호칭 알려 주기"부터 시작할 수 있습니다. AI가 자신의 이름과 분위기를 당신과 함께 정하고, 호칭만 묻습니다. 부탁하지 않으면 묻지 않습니다.

다른 사람의 게시물을 읽은 직후에 기억을 쓸 때는 반드시 확인이 나옵니다. 확인에는 어느 게시물을 읽었는지, 그리고 쓰려는 문장이 다른 사람의 게시물에 그대로 나와 있지 않은지가 함께 표시됩니다. 자리를 지키는 동안 (HEARTBEAT)에는 기억을 쓰지 않습니다. 손안의 CLI를 AI로 쓰고 있을 때는 "당신에 대해 기억하는 것"을 기본적으로 CLI에 넘기지 않습니다 (AI 연결의 토글로 넘길 수 있습니다).

## 권한

AI가 할 수 있는 일은 권한 설정으로 제어합니다. 기본값은 보수적이며 읽기 위주입니다.

권한은 용도별로 독립되어 있습니다. 채팅의 AI와 뒤에서 설명할 HEARTBEAT로 동작하는 AI는 따로 설정할 수 있으며, 한쪽을 느슨하게 해도 다른 쪽에는 영향이 없습니다.

## 자리를 비운 동안 실행하기 (HEARTBEAT)

앱이 실행되는 동안 정기적으로 AI를 돌리는 구조입니다. "새 알림 중에 중요한 것이 있으면 알려 줘" 같은 감시를 맡길 수 있습니다.

- 보고할 것이 없으면 조용히 있습니다
- 결과는 지정한 세션에 쌓입니다
- 연속으로 실패하면 자동으로 멈추고 경고가 나옵니다 (모르는 사이에 계속 고장 난 채로 있지 않도록)

사람 없이 동작하는 만큼 권한은 채팅과 별도이며, 기본값은 더 엄격합니다.

::: warning 계속 돌려 두는 비용에 주의
HEARTBEAT는 정기적으로 API를 호출합니다. 간격과 권한을 정한 뒤에 활성화하세요.
:::

## 외부 AI 에이전트에서 쓰기 (MCP)

방향을 거꾸로 해서, Claude Code나 Claude Desktop 같은 외부 AI 에이전트가 NoteDeck을 도구로 쓰게 할 수도 있습니다. NoteDeck은 MCP (Model Context Protocol) 서버를 내장하고 있어, 노트 검색과 게시 등 AI 채팅과 같은 capability를 tool로 넘깁니다.

1. 설정 → 권한 → "영구 API 토큰" (永続 API トークン)에서 토큰을 발급합니다. 발급 직후의 화면에 Claude Code용 등록 명령과 Claude Desktop용 설정 JSON이 나오므로 복사합니다
2. 외부에서 쓸 수 있는 범위는 같은 화면의 "외부 앱" (外部アプリ) 권한으로 정합니다. 기본값은 읽기뿐이며, 게시 등의 쓰기는 하나씩 허용합니다
3. 쓰기는 반드시 NoteDeck 화면에서 확인한 뒤에 실행됩니다. 외부 AI가 멋대로 게시하는 일은 없습니다

Claude Code처럼 HTTP로 연결하는 앱은 `http://127.0.0.1:19820/mcp`에 직접 연결합니다. Claude Desktop이나 Cline처럼 stdio로 실행하는 앱에는 함께 들어 있는 `notemaid`를 `notemaid mcp`로 넘기면, 실행 중인 NoteDeck으로 전달합니다. 둘 다 NoteDeck이 실행되는 동안에만 쓸 수 있습니다.
