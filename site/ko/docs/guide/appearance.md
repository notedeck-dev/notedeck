# 외관 바꾸기

## 테마

Misskey 테마를 그대로 쓸 수 있습니다. 본가에서 배포되는 테마 코드를 불러올 수 있고, [스토어](/ko/docs/guide/store)에서 설치하거나 직접 만들 수도 있습니다.

라이트 / 다크는 OS 설정을 따릅니다. 직접 고정할 수도 있습니다.

테마는 **계정마다 연결됩니다**. 서버마다 색을 바꿔 두면 어느 계정으로 조작하고 있는지 한눈에 알 수 있습니다. 적용 범위는 [프로파일](/ko/docs/deck/profiles) 전환을 따릅니다.

## 덱 배경 화면

덱 배경에 이미지를 설정할 수 있습니다. 칼럼 사이 틈으로 보이는 부분에 적용됩니다.

## CSS로 세세하게 바꾸기

테마로 닿지 않는 곳은 `custom.css`에 CSS를 직접 써서 조정할 수 있습니다. 파일 위치는 [설정 파일](/ko/docs/config/files)을 참고하세요.

노트의 요소에는 구별용 속성이 붙어 있습니다. 예를 들어 내 게시물과 다른 사람의 게시물을 다른 모양으로 하거나, 공개 범위에 따라 색을 바꾸는 일을 CSS만으로 할 수 있습니다.

::: warning 업데이트로 깨질 수 있습니다
`custom.css`는 내부 구조를 직접 건드리므로, 앱을 업데이트하면 듣지 않게 될 수 있습니다. 깨져서 표시가 이상해지면 먼저 `custom.css`를 비워서 원인을 좁혀 보세요.
:::

## 표시의 가벼움 고르기

기기에 맞춰 렌더링의 무게를 프리셋으로 전환할 수 있습니다. 메모리 절약 쪽으로도, 매끄러움 우선으로도 할 수 있습니다. 프레임 레이트는 기기에 맞춰 자동으로 조정됩니다.

세세한 수치까지 맞추고 싶다면 `performance.json5`를 직접 편집할 수 있습니다.
