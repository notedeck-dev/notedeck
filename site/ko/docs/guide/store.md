# 스토어로 확장하기

[misstore](https://store.notedeck.io)에서 다른 사람이 만든 것을 클릭 한 번으로 설치할 수 있습니다. 칼럼에서 바로 열 수 있습니다.

## 설치할 수 있는 것

| 종류 | 무엇을 하는가 |
|---|---|
| **테마** | 색 구성을 바꿉니다 |
| **플러그인** | 기능을 더합니다. 노트 메뉴 항목 추가, 게시물 가공 등 |
| **위젯** | 작은 표시 부품 |
| **쿼리** | [칼럼의 시야를 좁히는 조건](/ko/docs/guide/search#칼럼마다-시야-좁히기) |
| **스킬** | AI에게 익히게 하는 절차서 |

플러그인과 위젯은 Misskey와 같은 **AiScript**로 쓰여 있습니다. Misskey 본가에서 동작하는 플러그인의 사고방식이 그대로 통합니다.

## 켜고 끄기

설치한 것은 각각 전용 칼럼 (테마 / 플러그인 / 위젯 / 스킬 / 쿼리)에서 목록을 보고 관리합니다.

플러그인은 **계정마다 켜고 끌 수** 있습니다. 특정 서버에서만 쓰고 싶은 플러그인을 다른 계정에 영향을 주지 않고 활성화할 수 있습니다.

## 직접 쓰기

에디터와 라이브 미리보기가 내장되어 있습니다. 쓴 것은 그 자리에서 동작합니다. 스토어에 올리지 않고 손안에서만 써도 됩니다.

AiScript에서 `Nd:register_command`로 명령을 등록하면, 그 명령을 다음 모든 곳에서 호출할 수 있게 됩니다.

- 명령 팔레트
- 키 바인딩
- AI의 도구 (AI에게 "이거 써 줘"라고 부탁할 수 있습니다)
- 로컬 API (외부 앱이나 CLI에서)

즉 한 번 쓰면 어느 입구에서든 쓸 수 있습니다.

쓰는 방법은 [확장 만들기](/ko/docs/dev/)를 참고하세요.

## 안전 장치

플러그인과 위젯이 할 수 있는 일은 권한으로 제한됩니다. 게시나 계정 조작처럼 영향이 큰 조작에는 확인 대화 상자가 나옵니다.

신뢰할 수 없는 배포물을 설치하기 전에 무엇을 요구하는지 확인하세요. 권한 설정은 [설정 파일](/ko/docs/config/files)의 `permissions.json5`에서 관리되며, 플러그인 쪽에서는 고쳐 쓸 수 없습니다.
