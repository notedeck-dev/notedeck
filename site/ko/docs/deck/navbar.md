# 내비게이션 바

화면 왼쪽 끝의 세로로 긴 바입니다. VS Code의 활동 표시줄 (Activity Bar)과 같은 발상으로, **칼럼 토글 버튼**이 나란히 있습니다.

## 토글로 동작합니다

버튼을 누르면 해당하는 칼럼이 덱의 왼쪽 끝에 열립니다. 한 번 더 누르면 닫힙니다. 열리는 것은 항상 하나뿐이며, 다른 버튼을 누르면 바뀝니다. 읽지 않은 것이 있는 버튼에는 건수 배지가 붙습니다.

"잠깐 알림을 보고 싶다", "메모를 열고 싶다" 같은 때에 칼럼을 계속 두지 않고 잠시 불러낼 수 있습니다. 항상 보고 싶은 것은 일반 칼럼으로 놓으세요.

기본적으로는 타임라인, 알림, 멘션, 다이렉트, 메시지, 팔로우 요청, 서버 검색, 찾아보기, 위젯이 "모든 계정" (全アカウント) 버튼으로 나란히 놓입니다. 여기에 없는 것 (AI 등)은 "더 보기" (もっと)에서 열 수 있습니다.

## 버튼 바꾸기

내비게이션 바에 무엇을 놓을지는 사용자 지정할 수 있습니다. 설정의 내비게이션 바 항목에서 버튼 추가, 삭제, 순서 변경, 구분선 삽입을 할 수 있습니다.

계정을 지정한 버튼도 만들 수 있습니다. "misskey.io의 알림"과 "다른 서버의 알림"을 각각 다른 버튼으로 두는 구성이 가능합니다.

## 프로파일과는 독립

내비게이션 바의 구성은 `navbar.json5`에 저장되며, [프로파일](/ko/docs/deck/profiles)과는 독립적으로 다뤄집니다. 프로파일을 전환해도 내비게이션 바는 바뀌지 않습니다. 파일을 날것 그대로 편집하는 탭은 [개발자 모드](/ko/docs/#개발자-모드)에서 나타납니다.

::: tip 접기
내비게이션 바의 너비는 드래그로 바꿀 수 있습니다. 좁혀 가면 아이콘만 표시하는 형태로 바뀝니다.

고른 너비는 다음 실행 때도 이어집니다. 창을 좁혀 둔 동안에는 자동으로 아이콘만 표시되지만, 다시 넓히면 원래 너비로 돌아옵니다.
:::
