# 칼럼과 창

NoteDeck의 화면은 **칼럼**과 **창**으로 이루어져 있습니다. 이 둘을 어떻게 나눠 쓰는지 알면, 나머지는 배치하기만 하면 됩니다.

## 어느 쪽이 될지는 "계속 흘러가는가"로 정해집니다

| | 칼럼 | 창 |
|---|---|---|
| 두는 것 | 계속 흘러가는 것 (타임라인, 알림, 채팅, AI) | 지금만 보고 싶은 것 (노트 상세, 프로필, 설정) |
| 나타나는 방식 | 덱에 세로로 긴 영역으로 나란히 놓입니다 | 앞쪽에 떠 있는 작은 창 |
| 닫으면 | 프로파일에 저장되어 다음에도 나타납니다 | 사라집니다. 저장되지 않습니다 |

노트를 클릭하면 상세가 **창**으로 열리는 것은 그것이 일시적인 열람이기 때문입니다. 반면 타임라인은 계속 흘러가므로 **칼럼**이 됩니다.

## 칼럼 다루기

- **추가** — "칼럼 추가" (カラム追加, ＋) 버튼 또는 명령 팔레트 (`Ctrl+K`)에서
- **순서 변경** — 칼럼 헤더를 드래그
- **너비 변경** — 칼럼 경계를 드래그. 너비는 기억됩니다
- **삭제** — 칼럼 헤더의 메뉴에서

### 별도 창으로 분리하기

칼럼은 팝아웃해서 OS의 별도 창으로 만들 수 있습니다. 멀티 모니터에서 알림만 보조 디스플레이에 두는 식으로 쓸 수 있습니다.

**PiP** (항상 위에 표시되는 작은 창)도 지원합니다. 다른 앱을 조작하면서 타임라인을 계속 흘려 둘 수 있습니다.

## 계정 지정

칼럼마다 "어느 계정으로 동작할지"를 고를 수 있습니다.

- **특정 계정** — 그 계정의 시점으로 표시합니다 (일반 타임라인 등)
- **모든 계정** (全アカウント) — 모든 계정의 내용을 칼럼 하나에 모아 표시합니다

모아 보기 (cross-account)를 지원하는 것은 **알림, 검색, 채팅, 멘션, 다이렉트, 팔로우 요청**입니다. 여러 서버를 쓰면서 알림을 놓치고 싶지 않다면, 알림 칼럼 하나를 "모든 계정"으로 두는 것이 편합니다.

## 칼럼 종류

칼럼 추가 대화 상자는 세 그룹으로 나뉩니다.

### 계정

내 계정에 연결된 것.

타임라인 / 알림 / 드라이브 / 팔로우 요청 / 리스트 / 안테나 / 즐겨찾기 / 클립 / 멘션 / 다이렉트 / 채팅 / 도전 과제

### 서버

서버 쪽 정보를 보는 것. 로그인하지 않아도 볼 수 있는 것이 많습니다.

서버 정보 / Misskey에 대하여 / 커스텀 이모지 / 광고 / 둘러보기 / 공지사항 / 검색 / 찾아보기 / 채널 / 역할 / 갤러리 / Misskey Play / 페이지 / 유저 / 차트 / 연합

### 도구 칼럼

NoteDeck 고유의 작업용 칼럼. Misskey 서버와 직접 관계없는 것도 포함합니다.

| 칼럼 | 무엇을 하는가 |
|---|---|
| AI | AI와 대화합니다. 세션을 전환하며 기록을 남길 수 있습니다 |
| 메모 (メモ) | 로컬 메모. Markdown 파일로 저장되어 Obsidian 등에서도 열 수 있습니다 |
| 작업 (タスク) | 할 일 관리 |
| 스크래치 패드 (スクラッチパッド) | 쓰고 버리는 텍스트 영역 |
| 테마 / 플러그인 / 위젯 / 스킬 / 쿼리 | 설치한 것의 목록과 켜기/끄기, 편집 |
| 스트림 (ストリーム) | 서버와 주고받는 WebSocket 통신을 실시간으로 들여다봅니다 |
| API 콘솔 / API 문서 | Misskey API를 직접 호출하고 사양을 찾아봅니다 |

"스트림"은 Misskey의 이면에서 무엇이 흐르고 있는지 그대로 볼 수 있는 칼럼입니다. 동작이 수상할 때 원인을 좁히는 데도, 구조를 배우는 데도 쓸 수 있습니다.

## 창 종류

창은 직접 "추가"하는 것이 아니라 조작에 따라 열립니다.

- **상세** — 노트 상세, 프로필, 팔로우 목록
- **인스펙터** — 노트와 알림의 원시 데이터 (Raw JSON). API 키 등 민감한 필드는 자동으로 마스킹되며, 필요할 때만 표시할 수 있습니다
- **도구** — 로그인, 각종 에디터, 설정

::: tip 칼럼이 너무 많아 잘려 보일 때
가로로 놓는 수를 늘리면 칼럼이 좁아집니다. 용도별로 [프로파일](/ko/docs/deck/profiles)을 나눠 전환하는 편이 쾌적합니다.
:::
