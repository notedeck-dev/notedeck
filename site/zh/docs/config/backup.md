# 备份

## 要保护的是什么

NoteDeck 持有的数据分为两部分。

| | 内容 | 位置 |
|---|---|---|
| **设置** | 列配置、主题、快捷键、插件、备忘等 | [设置文件夹](/zh/docs/config/files#设置在哪里) |
| **帖子缓存** | 刷过的帖子的存档、账户信息 | `notecli.db` |

## 备份设置

设置支持导出 / 导入。在另一台电脑上导入导出的文件，就能重现相同的环境。

对象是[设置文件](/zh/docs/config/files#什么写在哪里)中列出的文件和文件夹。**不包含 API 密钥和访问令牌**（因为它们在操作系统的钥匙串中）。在迁移目标上需要重新登录。

## 备份帖子

**只需复制** `notecli.db`。这是一个 SQLite 文件，仅这一个文件就完整包含了存档的帖子和账户信息。

请在退出应用后再复制。在应用运行时复制，可能会拿到写入到一半的状态。

::: warning 删除后无法恢复
即使卸载应用，设置和缓存也会保留；但如果删除整个设置文件夹，存档的帖子也会一起消失。能从服务器重新获取的，只有服务器上仍然存在的内容。
:::

## Misskey 端的数据

自己的帖子、关注、收藏等存放在服务器上的数据，其备份属于 Misskey 端的功能。请从服务器的设置页面导出。NoteDeck 的备份保存的仅仅是“这台设备的状态”。
