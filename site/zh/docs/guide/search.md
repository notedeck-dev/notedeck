# 查找帖子

NoteDeck 的搜索分为两层。

| | 在哪里找 | 能找到什么 |
|---|---|---|
| **服务器搜索**（サーバー検索） | Misskey 服务器 | 服务器纳入搜索范围的帖子 |
| **客户端搜索**（クライアント検索） | 本地数据库 | 在你的界面上刷过的帖子（跨所有服务器、所有账户） |

“明明看过却找不到”，多数情况是因为那条帖子不在服务器的搜索范围内。NoteDeck 会把显示过的帖子也存在本地，所以可以从那里找到。两者都以列的形式打开，也可以并排使用。

## 客户端搜索列

“客户端搜索”列会跨服务器和账户，一次性搜索存在本地的帖子。即使不记得是在哪个服务器上看到的，也能找到。

- 除了搜索词，还可以按范围（全部 / 特定服务器 / 特定账户）、发帖者（`name` 或 `name@host`）、时间段、是否有附件进行筛选
- 搜索词为空时也可以只靠筛选条件查找，例如“最近一周带图片的帖子”
- 搜索词和筛选条件会保存在列中，因此可以保留条件一直开着
- 在多个服务器上看到的同一条帖子会合并为一行，在哪个服务器上看到的可以从该行的明细中确认
- 即使没有登录服务器，也能查找本地已有的内容

::: warning 聊天不在搜索范围内
聊天消息无论用服务器搜索还是客户端搜索都无法搜到。
:::

## 帖子如何保留在本地

时间线上刷过的帖子会自动存入本地 SQLite，无需任何特别操作。保留多少可以在设置的缓存中选择。请注意，所有经过你眼前的帖子，包括仅关注者可见和指定用户可见的帖子，都会以未加密的形式保存。

因此会有以下效果：

- 即使帖子从服务器上删除，本地的副本仍然保留
- 即使联合中断、看不到对方服务器，已获取的帖子仍可阅读
- 离线时也能重读过去的时间线

::: warning 只会保存“刷过的内容”
你从未显示过的帖子不在本地。无法回溯未关注用户的历史帖子。
:::

## 按列缩小视野

与搜索不同，还有一种叫做**列查询**的机制。它可以用你自己写的条件表达式，筛选流入列中的帖子。

- 只显示包含特定关键词的帖子
- 排除来自特定用户或服务器的帖子
- 只看带附件的帖子

条件用 AiScript 表达式编写。写好的条件可以命名保存，在多个列中复用。也可以从[商店](/zh/docs/guide/store)安装别人写的查询。

查询在“查询”（クエリ）列中管理，在时间线列的筛选菜单中切换应用。
