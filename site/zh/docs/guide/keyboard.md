# 键盘操作

NoteDeck 的设计目标是不用鼠标也能操作。拿不准时，请打开**命令面板**。

## 命令面板

按 `Ctrl+K` 打开（不在输入文本时也可以按 `/` 或 `?`）。添加列、切换账户、打开设置、发帖 — 主要操作都可以在这里按名称查找并执行。

插件和你自己用 AiScript 写的命令也会出现在同一个面板中。

## 主要快捷键

按键分为两类。**带修饰键的**在应用内的任何地方都有效；**单键**在输入文本时无效（以免妨碍输入）。

| 操作 | 带修饰键 | 单键 |
|---|---|---|
| 命令面板 | `Ctrl+K` | `/` `?` |
| 搜索 | `Ctrl+Shift+F` | `s` |
| 通知 | — | `i` |
| 发帖 | `Ctrl+Shift+N` | `p` `n` |
| 添加列 | `Ctrl+Shift+A` | — |
| 关闭列 | `Ctrl+W` | — |
| 选择列 | `Ctrl+1`〜`Ctrl+9` | `Shift+H` / `Shift+L` 左右移动 |
| 切换配置文件 | `Alt+1`〜`Alt+9` | `g` 打开菜单 |
| 上下移动帖子 | — | `j` / `k` |
| 回复 / 回应 / 转发帖子 | — | `r` / `e` / `q` |
| 打开/关闭侧边栏 | `Ctrl+\` | — |
| 设置 / 教程 | `Ctrl+,` / `F1` | — |
| 界面放大 / 缩小 / 重置 | `Ctrl++` / `Ctrl+-` / `Ctrl+0` | — |
| Boss Key（隐藏窗口） | `Ctrl+Shift+B` | — |
| 快速发帖（从任何地方发帖） | `Ctrl+Alt+N` | — |

`Ctrl+Shift+B`（Boss Key）和 `Ctrl+Alt+N`（快速发帖）是**操作系统全局的热键**。即使 NoteDeck 在后台，或者你正在使用其他应用，它们也有效。

## 自定义按键

所有快捷键都可以修改。与 VS Code 的 `keybindings.json` 思路相同，采用由用户覆盖默认绑定的方式。设置保存在 `keybinds.json5` 中。

每个快捷键都有适用范围（作用域）。

- `global` — 在应用内始终有效。用于带修饰键的按键
- `body` — 输入文本时无效。用于单键
- `os-global` — 在整个操作系统中有效（仅桌面版，必须带修饰键）。通过键位设置中的“操作系统全局”（OS 全体）开关，可以分配给任何命令

如果把单键设为 `global`，就无法输入那个字符了，所以没有修饰键的按键请指定 `body`。

文件的位置和编辑方法请参阅[设置文件](/zh/docs/config/files)。
