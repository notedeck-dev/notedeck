# 更改外观

## 主题

可以直接使用 Misskey 的主题。既可以载入为 Misskey 官方版本发布的主题代码，也可以从[商店](/zh/docs/guide/store)安装，还可以自己制作。

浅色 / 深色跟随操作系统的设置，也可以手动固定。

主题**与每个账户绑定**。为每个服务器设置不同的颜色，就能一眼看出正在用哪个账户操作。适用范围随[配置文件](/zh/docs/deck/profiles)的切换而变化。

## Deck 壁纸

可以为 Deck 的背景设置图片，它会显示在列与列之间的空隙中。

## 用 CSS 精细调整

主题覆盖不到的地方，可以直接在 `custom.css` 中写 CSS 来调整。文件位置请参阅[设置文件](/zh/docs/config/files)。

帖子的各个元素都带有用于识别的属性。例如让自己的帖子和他人的帖子显示不同的样式，或根据可见性改变颜色，只用 CSS 就能做到。

::: warning 更新后可能失效
`custom.css` 直接触及内部结构，因此应用更新后可能会失效。如果出现问题、显示异常，请先清空 `custom.css` 来排查。
:::

## 选择显示的轻重

可以根据设备，通过预设切换渲染的负载，既可以偏向省内存，也可以优先流畅度。帧率会根据设备自动调整。

如果想精确调整具体数值，可以直接编辑 `performance.json5`。
