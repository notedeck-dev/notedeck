# 更改外观

## 主题

可以直接使用 Misskey 的主题。既可以载入为 Misskey 官方版本发布的主题代码，也可以从[商店](/zh/docs/guide/store)安装，还可以自己制作。

浅色 / 深色跟随操作系统的设置，也可以手动固定（单键 `d` 切换）。

整个应用只有一个主题，但列可以映射**该账户在 Misskey 侧选择的主题**（没有则为服务器的默认主题）。每个服务器颜色都不同，就能一眼看出正在用哪个账户操作。

## Deck 壁纸

可以为 Deck 的背景设置图片，它会显示在列与列之间的空隙中。

## 宠物

可以在 Deck 上放一只宠物。把 [petdex.dev](https://petdex.dev) 的 slug 或 URL 填入外观设置的“宠物”（ペット）中即会出现，还可以调整大小。它会随着 AI 的活动而动。

## 界面大小

用 `Ctrl++` / `Ctrl+-` 放大、缩小整个界面，用 `Ctrl+0` 恢复。把帖子正文“喵化”（にゃ化）的设置也在这里。

## 用 CSS 精细调整

主题覆盖不到的地方，可以直接在 `custom.css` 中写 CSS 来调整。文件位置请参阅[设置文件](/zh/docs/config/files)。

帖子的各个元素都带有用于识别的属性。例如让自己的帖子和他人的帖子显示不同的样式，或根据可见性改变颜色，只用 CSS 就能做到。

::: warning 更新后可能失效
`custom.css` 直接触及内部结构，因此应用更新后可能会失效。如果出现问题、显示异常，请先清空 `custom.css` 来排查。编辑会留下历史记录。
:::

## 选择显示的轻重

可以根据设备，用一个滑块在“省内存”到“高性能”之间调整渲染的负载。打开“根据电源、网络、窗口状态自动调整”后，在电池供电或省电模式下会停止图片预读和动画表情，在按流量计费的网络下图片 / 视频改为点击加载，窗口隐藏期间会暂停时间线的订阅。

如果想精确调整具体数值，可以直接编辑 `performance.json5`（直接编辑原文的标签页在[开发者模式](/zh/docs/#开发者模式)下出现）。
