# 用商店扩展

可以从 [misstore](https://store.notedeck.io) 一键安装别人制作的内容，也可以直接从列中打开它。

## 可以安装什么

| 类型 | 做什么 |
|---|---|
| **主题** | 更改配色 |
| **插件** | 增加功能，例如为帖子菜单添加项目、加工帖子等 |
| **小工具** | 小型显示组件 |
| **查询** | [缩小列视野的条件](/zh/docs/guide/search#按列缩小视野) |
| **技能** | 让 AI 掌握的操作手册 |

插件和小工具与 Misskey 一样用 **AiScript** 编写。Misskey 官方版本中插件的思路可以原样沿用。

## 切换启用与停用

安装的内容分别在各自专用的列（主题 / 插件 / 小工具 / 技能 / 查询）中列出和管理。

插件可以**按账户开关**。只想在特定服务器上使用的插件，可以在不影响其他账户的情况下启用。

## 自己编写

内置了编辑器和实时预览，写好的内容当场就能运行。不发布到商店、只在本地使用也完全可以。

在 AiScript 中用 `Nd:register_command` 注册命令后，就可以从以下所有地方调用该命令：

- 命令面板
- 快捷键
- AI 的工具（可以请 AI “用这个”）
- 本地 API（从外部应用或 CLI）

也就是说，写一次就能从任何入口使用。

写法请参阅[制作扩展](/zh/docs/dev/)。

## 安全机制

插件和小工具能做的事情受到权限的限制。发帖、账户操作等影响较大的操作会弹出确认对话框。

在安装不可信的内容之前，请确认它要求了哪些权限。权限设置通过[设置文件](/zh/docs/config/files)中的 `permissions.json5` 管理，插件无法改写。
