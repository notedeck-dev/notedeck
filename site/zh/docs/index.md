# NoteDeck 是什么

NoteDeck 是一款以 **Deck** 形式使用 Misskey 的桌面 / 移动应用。时间线、通知、搜索、聊天等以纵向的列横向排开，让你在一个界面里同时使用多个账户和服务器。

与在浏览器中打开的 Misskey 网页版相比，它有以下不同：

- **可以跨账户排列** — 为每个列分配不同的账户，或把所有账户的通知汇总到同一个列中
- **刷过的帖子会留在本地** — 显示过的帖子会存入本地数据库，之后可以全文搜索
- **可以使用操作系统的功能** — 全局热键、原生通知、系统托盘、拆分到独立窗口

::: info 应用界面目前仅有日语
应用界面目前只提供日语（翻译工作在 [#135](https://github.com/notedeck-dev/notedeck/issues/135) 中跟进）。本文档在按钮和菜单名称旁附上日语原文，方便你在界面上找到它们。
:::

## 三个基本概念

记住这三个概念，就能看懂 NoteDeck 的界面。

| 概念 | 是什么 | 会保留吗 |
|---|---|---|
| **列** | 放置持续刷新内容的纵长区域。时间线、通知、聊天、AI 等 | 会保存。重启应用后依然存在 |
| **窗口** | 临时打开的小窗口。帖子详情、个人资料、设置、编辑器等 | 关闭即消失，不会保存 |
| **配置文件** | 完整保存下来的列排列方式。可按用途切换 | 会保存 |

“持续刷新的东西放列，只是现在想看的东西开窗口”，就是这样区分的。详情请参阅[列与窗口](/zh/docs/deck/columns)。

## 为什么叫它“IDE”

NoteDeck 自称 Integrated Deck Environment（集成 Deck 环境）。正如编辑器内置了调试器和终端后就不再只是“写文本的地方”，NoteDeck 也不只是“读和写” Misskey 的工具。

- 原样查看与服务器之间通信的[检查器](/zh/docs/deck/columns#工具类列)
- 从[商店](/zh/docs/guide/store)安装的插件、主题和小工具
- 能把自己写的处理变成命令的 AiScript
- 让 [AI](/zh/docs/guide/ai) 作为搭档常驻的机制

即使不用这些，它也是一个完整的普通客户端；但越深入，它就越成为你自己的工具。
