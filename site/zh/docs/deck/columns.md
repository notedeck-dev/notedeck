# 列与窗口

NoteDeck 的界面由**列**和**窗口**组成。弄清楚这两者的分工，剩下的就只是排列了。

## 用哪个取决于“是否持续刷新”

| | 列 | 窗口 |
|---|---|---|
| 放什么 | 持续刷新的东西（时间线、通知、聊天、AI） | 只是现在想看的东西（帖子详情、个人资料、设置） |
| 呈现方式 | 作为纵长区域排列在 Deck 中 | 浮在前方的小窗口 |
| 关闭后 | 保存在配置文件中，下次仍会显示 | 消失，不会保存 |

点击帖子时详情会在**窗口**中打开，因为这只是临时浏览。而时间线会持续刷新，所以是**列**。

## 操作列

- **添加** — 通过“添加列”（カラム追加，＋）按钮或命令面板（`Ctrl+K`）
- **重新排序** — 拖动列的标题栏
- **调整宽度** — 拖动列之间的边界。宽度会被记住
- **删除** — 通过列标题栏的菜单

### 拆分到独立窗口

列可以弹出为操作系统的独立窗口。例如在多显示器环境下，可以只把通知放到副显示器上。

还支持**画中画**（始终置顶的小窗口），可以一边操作其他应用，一边让时间线持续刷新。

## 分配账户

每个列都可以选择“用哪个账户运行”。

- **特定账户** — 以该账户的视角显示（普通的时间线等）
- **全部账户**（全アカウント） — 把所有账户的内容汇总到一个列中显示

支持汇总显示（cross-account）的有**通知、搜索、聊天、提及、指定用户、关注请求**。如果你同时使用多个服务器又不想漏看通知，只放一个设为“全部账户”的通知列是最省事的。

## 列的类型

“添加列”对话框分为三组。

### 账户

与你自己的账户相关的内容。

时间线 / 通知 / 网盘 / 关注请求 / 列表 / 天线 / 收藏 / 便签 / 提及 / 指定用户 / 聊天 / 成就

### 服务器

查看服务器端信息的内容。其中很多不登录也能查看。

服务器信息 / 关于 Misskey / 自定义表情符号 / 广告 / 发现 / 公告 / 搜索 / 查询 / 频道 / 角色 / 图集 / Misskey Play / 页面 / 用户 / 图表 / 联合

### 工具类列

NoteDeck 独有的工作用列。其中也包括与 Misskey 服务器没有直接关系的列。

| 列 | 做什么 |
|---|---|
| AI | 与 AI 对话。可以切换会话并保留历史 |
| 备忘（メモ） | 本地备忘。以 Markdown 文件保存，也能用 Obsidian 等打开 |
| 任务（タスク） | 管理待办事项 |
| 草稿板（スクラッチパッド） | 随写随弃的文本区域 |
| 主题 / 插件 / 小工具 / 技能 / 查询 | 已安装内容的列表、开关与编辑 |
| 流（ストリーム） | 实时查看与服务器之间的 WebSocket 通信 |
| API 控制台 / API 文档 | 直接调用 Misskey API、查阅规范 |

“流”是能原样看到 Misskey 幕后正在传输什么的列。既可以用来排查异常行为，也可以用来学习其运作机制。

## 窗口的类型

窗口不是自己“添加”的，而是根据操作打开的。

- **详情** — 帖子详情、个人资料、关注列表
- **检查器** — 帖子和通知的原始数据（Raw JSON）。API 密钥等敏感字段会自动遮蔽，只在需要时显示
- **工具** — 登录、各种编辑器、设置

::: tip 列太多显示不下时
横向排列的列越多，每个列就越窄。按用途分成不同的[配置文件](/zh/docs/deck/profiles)并切换使用会更舒适。
:::
