# 配置文件

配置文件是**完整保存下来的列排列方式**。可以按用途分别创建，一键切换。

它与“个人资料”（用户信息）是两回事。NoteDeck 把应用功能意义上的称为**配置文件**（日语界面中为 プロファイル），把 Misskey 的用户信息称为**个人资料**（プロフィール），以示区分。

## 使用场景

- **日常用** — 首页、通知、消息
- **活动用** — 并排放置特定频道和话题标签搜索
- **工作用** — AI、备忘、客户端搜索

当想看的内容随场合而变时，就不必每次都增删列了。

## 切换与管理

只需在配置文件菜单（单键 `g`）的列表中选择，整个 Deck 就会随之替换。也可以用 `Alt+1`〜`Alt+9` 直接切换，或通过 [`notedeck://profile/<名称>`](/zh/docs/guide/links) 链接切换。新建和删除也在同一个菜单中进行，名称等的编辑则在配置文件编辑器中完成。

保存的内容是“哪些列、按什么顺序、以什么宽度排列”，以及拆分出去的操作系统窗口的位置和大小。[导航栏](/zh/docs/deck/navbar)的按钮配置独立于配置文件，切换时不会改变。账户信息本身也不与配置文件绑定，无论在哪个配置文件中，都能使用所有已添加的账户。

首次启动时，会从默认列配置的配置文件开始。

## 与窗口的关系

配置文件和窗口是两个不同的维度。

- **配置文件** = 列配置的所有者
- **窗口** = 显示它的地方

同一个配置文件可以在多个窗口中打开。在其中一个窗口中添加列，所有打开该配置文件的窗口都会同步反映。关闭窗口不会改变配置文件的内容。
