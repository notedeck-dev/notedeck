# 导航栏

位于界面最左侧的纵长栏。与 VS Code 的活动栏思路相同，上面排列着**列的切换按钮**。

## 作为开关使用

按下按钮，对应的列就会在 Deck 的最左侧打开；再按一次就会关闭。同一时间只会打开一个，按下其他按钮时会替换为对应的列。

当你只是“想看一眼通知”“想打开备忘”时，可以临时调出列，而不必一直摆在 Deck 里。需要一直看着的内容，请作为普通列排列。

## 更换按钮

导航栏上放什么可以自定义。在设置的导航栏项目中，可以添加、删除和重新排序按钮，以及插入分隔线。

也可以创建指定了账户的按钮。例如把“misskey.io 的通知”和“另一个服务器的通知”作为两个独立的按钮放置。

## 独立于配置文件

导航栏的配置保存在 `navbar.json5` 中，与[配置文件](/zh/docs/deck/profiles)分开处理。切换配置文件不会改变导航栏。

::: tip 折叠
拖动可以改变导航栏的宽度。越拖越窄时，会切换为只显示图标。

选择的宽度在下次启动时也会保留。窗口较窄时会自动只显示图标，再次放宽后会恢复原来的宽度。
:::
