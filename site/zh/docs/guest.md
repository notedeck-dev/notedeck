# 不登录试用

无需注册账户，也无需邮箱地址，就能浏览服务器上的公开内容。想先试试好不好用，或者想不登录看看其他服务器时，可以使用这个功能。

## 添加访客

在登录窗口中输入服务器的主机名，然后选择“**以访客身份浏览**”（ゲストとして閲覧）。不会进行认证，而是作为只使用该服务器公开 API 的账户添加。

可以同时拥有多个服务器的访客，也可以与已登录的账户混用。

## 能做的与不能做的

::: tip 能做的

- 浏览公开时间线（本地、全局等）
- 浏览频道、图集、页面等公开内容
- 查看服务器信息、自定义表情符号和联合图表
- 使用主题、小工具等本地工具

:::

::: warning 不能做的

- 发帖、回应、关注
- 接收通知
- 管理网盘、列表、天线、便签

:::

无法使用的列会在“添加列”（カラム追加）的列表中注明，并且无法选择。

能看到的范围取决于各服务器的公开设置。如果服务器设置为不向未登录用户显示任何内容，那么访客将什么也看不到。

## 停止使用

只需删除访客账户即可。在账户菜单中选择“**删除访客**”（ゲストを削除）。服务器上不会留下任何痕迹。

如果想正式登录，请照常[添加账户](/zh/docs/first-run#_1-添加账户)。访客和已登录账户是分开处理的，不需要先删除访客再重新添加。
