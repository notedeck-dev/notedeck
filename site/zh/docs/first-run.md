# 首次设置

首次启动时，由于还没有添加账户，会自动开始教程。按照引导操作，就能完成从登录到整理 Deck 的全部步骤。

中途退出也没关系，已经设置的内容会保留。之后可以在 [About 窗口](#重新进行教程)中选择“查看教程”（チュートリアルを見る）继续。

## 1. 添加账户

在登录窗口中输入 Misskey 服务器的主机名（例如 `misskey.io`）并进行认证。浏览器会打开服务器端的授权页面，允许后就会回到 NoteDeck。

登录信息（访问令牌）保存在操作系统的钥匙串中。

- macOS → 钥匙串访问
- Windows → 凭据管理器
- Linux → Secret Service（GNOME Keyring 等）

令牌绝不会以明文写入应用的设置文件。

::: tip 多个账户
重复同样的步骤，就能添加其他服务器上的账户，数量不限。每个列都可以选择用哪个账户运行。
:::

## 2. 打造属于你的 Deck

NoteDeck 通过排列列来使用。首次启动时 Deck 里已经排好了一些列，它们都是“全部账户”（全アカウント）— 把已添加的所有账户汇总显示的列。账户添加得越多，就有越多服务器的内容汇入同一个列。

这些列可以直接使用，也可以删除。在列的标题栏中可以重新排序、调整宽度和删除；通过“添加列”（カラム追加，＋）可以添加通知、搜索、聊天等所需的列。哪些东西可以放在哪里，请参阅[列与窗口](/zh/docs/deck/columns)。

即使全部删光，也可以在空 Deck 上显示的“以默认布局开始”（既定の構成で始める）恢复最初的排列。

## 3. （可选）接入 AI

如果要使用 AI 功能，请登记你自己的 API 密钥。不使用 AI，其他功能也都能正常运行。

1. 在连接管理窗口中登记 Anthropic、OpenAI 等提供商的 API 密钥
2. 在 AI 设置中，选择已登记的连接作为 AI 提供商
3. 通过侧边栏的 AI 按钮打开 AI 列

API 密钥保存在操作系统的钥匙串中，不会写入设置文件。详情请参阅[与 AI 一起使用](/zh/docs/guide/ai)。

## 重新进行教程

随时都可以从头再来。打开 **About 窗口**，选择“查看教程”（チュートリアルを見る）。已完成的步骤会被自动跳过。
