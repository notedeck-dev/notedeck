# 首次设置

首次启动时，由于还没有添加账户，会自动开始教程。按照引导操作，就能完成从登录到查看通知的全部步骤。

中途退出也没关系，已经设置的内容会保留。之后可以通过设置菜单顶部的[**教程**](#重新进行教程)（チュートリアル）继续。

## 1. 添加账户

在添加账户的窗口中输入 Misskey 服务器的主机名（例如 `misskey.io`）并进行认证。浏览器会打开服务器端的授权页面，允许后回到 NoteDeck，点击“**已认证**”（認証しました）。失败时点“重试”（やり直す）从头开始。

登录信息（访问令牌）保存在操作系统的钥匙串中。

- macOS → 钥匙串访问
- Windows → 凭据管理器
- Linux → Secret Service（GNOME Keyring 等。没有的环境下会转存到加密文件）
- Android → Android Keystore

令牌绝不会以明文写入应用的设置文件。

::: tip 多个账户
重复同样的步骤，就能添加其他服务器上的账户，数量不限。每个列都可以选择用哪个账户运行。
:::

## 2. 打造属于你的 Deck

NoteDeck 通过排列列来使用。首次启动时 Deck 里已经排好了首页时间线和提及两个列，它们都是“全部账户”（全アカウント）— 把已添加的所有账户汇总显示的列。账户添加得越多，就有越多服务器的内容汇入同一个列。

这些列可以直接使用，也可以删除。在列的标题栏中可以重新排序、调整宽度和删除；通过“添加列”（カラム追加，＋）可以添加通知、搜索、聊天等所需的列。哪些东西可以放在哪里，请参阅[列与窗口](/zh/docs/deck/columns)。

即使全部删光，也可以在空 Deck 上显示的“以默认布局开始”（デフォルトの構成で始める）恢复最初的排列。

## 3. （可选）接入 AI

从这里开始已在首次教程之外。如果要使用 AI 功能，请登记你自己的 API 密钥。不使用 AI，其他功能也都能正常运行。

1. 在设置菜单的**连接**（接続）中登记 Anthropic、OpenAI 等提供商的 API 密钥
2. 在设置菜单的**智能体**（エージェント）中，选择已登记的连接作为 AI 提供商
3. 从导航栏的“更多”（もっと）打开 AI 列（也可以把 AI 按钮放到导航栏上）

API 密钥保存在操作系统的钥匙串中，不会写入设置文件。详情请参阅[与 AI 一起使用](/zh/docs/guide/ai)。

## 重新进行教程

打开设置菜单顶部的**教程**（チュートリアル），会显示按类别划分的清单。每一项都可以通过“开始”“继续”“再来一次”推进，已完成的会原样保留。“制作扩展”类别在[开发者模式](/zh/docs/#开发者模式)下开放。
