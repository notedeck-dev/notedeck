# 対応サーバー

NoteDeck が対応するのは、Misskey 本家と「Misskey を名乗り続けるフォーク」です。名前が別物になったフォーク (Sharkey、CherryPick、Iceshrimp など) には対応しません。ログイン画面でそのサーバーの種類を表示し、未対応ならその旨を出します。

## 対応するサーバー

| サーバー | 補足 |
|---|---|
| Misskey (本家) | すべての機能の基準 |
| Misskey.io | 独自機能は下の表のとおり |
| yamisskey | やみ TL / やみモード / プライベート |
| Misskey tempura | セミパブリック / 引用一覧 / リモート絵文字リアクション |
| hanamisskey | はなみ TL / はなみ検索 / はなモード |

一覧に無い小規模なフォークは本家として扱います。本家と同じ API で動く機能はそのまま使えます。

## フォーク独自の機能

NoteDeck はフォークの名前で動きを変えません。サーバーが返す情報 (エンドポイントの一覧、ロールポリシー、サーバー情報) から「その機能があるか」を見て、あるときだけ入口を出します。

### どのフォークでも自動で動くもの

- **独自タイムライン** (やみ TL、はなみ TL、バブル TL など): カラム追加の一覧に自動で出ます
- **モード** (やみモード、はなモード): 投稿フォームのトグルと、ノートのバッジ
- **タイムラインのフィルター** (Bot を除く、センシティブを除く など): そのサーバーが受けるものだけ出ます
- **公開範囲の制限**: ロールで使えない公開範囲は選択肢から消えます

### フォークごとのもの

| サーバー | 機能 | 状態 |
|---|---|---|
| Misskey.io | 画像 TL | ソーシャル TL に「ファイル付き」のフィルターで同じ結果になります。専用のカラムは置きません |
| Misskey tempura | セミパブリック (パブリック (非 LTL)) | 実装済み。投稿できるアカウントだけ選択肢が出て、ノートには専用のアイコンが付きます。返信とリノートは元の公開範囲を引き継ぎます (実機での確認待ち) |
| Misskey tempura | 引用一覧 | 実装済み。ノート詳細に「引用」タブが出ます (実機での確認待ち) |
| Misskey tempura | リモート絵文字でのリアクション | 動きます |
| hanamisskey | はなみ TL | 動きます |
| hanamisskey | はなみ検索 | 動きます。サーバー検索がはなみ検索に置き換わります |
| hanamisskey | はなモード | 実装済み (実機での確認待ち) |
| yamisskey | やみ TL / やみモード | 実装済み (実機での確認待ち) |
| yamisskey | プライベート (自分のみに公開) | 実装済み。投稿フォームの選択肢は yamisskey のアカウントだけに出ます。宛先の無いダイレクトを「プライベート」のアイコンで見せる表示は、どのサーバーでも同じです (実機での確認待ち) |

### あえて対応しないもの

- **Misskey.io の次元 (TL カラムで次元を選ぶ)**: サーバー側が次元を短時間で忘れる設計で、ずっと開いておくカラムに載せる性質のものではないため、見送っています。投稿フォームでの次元の指定とノートの次元表示は、要望に応じて検討します ([#1201](https://github.com/notedeck-dev/notedeck/issues/1201))
- **はなモードとセミパブリックの表示をひとつにすること**: どちらも「パブリックだがローカル TL に載らない」ですが、はなモードはユーザーの状態、セミパブリックはノートごとの選択で、仕組みが別です。ひとつの表現にすると「どちらで投稿されたか」が消えるので、別々に見せます
- **名前が別物になったフォーク**: 対応範囲が広がりすぎて維持できなくなるため、対象外です

## 知っておくこと (サーバー側の挙動)

NoteDeck の不具合に見えますが、サーバー側の仕様です。

- **Misskey.io** にはチャットの API がありません。チャットカラムは使えません
- **yamisskey** はログインしていない相手にノートを返しません。ゲストでは何も表示されません。パブリック投稿と連合にロールの付与が要る設定になっていることがあります
- **Misskey tempura** では、他人のセミパブリックが返信一覧・リノート一覧・サーバー検索に出ません。ソーシャル TL ではリアルタイムには流れますが、読み直すと消えます
- **hanamisskey** では、ログインしていないとおすすめノートが取れません

## 要望と未対応の機能

フォークごとの独自機能の棚卸しと、まだ対応していない機能の候補は GitHub の追跡 issue にあります。対応してほしい機能があれば、そこにコメントしてください。
