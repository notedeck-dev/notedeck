# カラムとウィンドウ

NoteDeck の画面は**カラム**と**ウィンドウ**でできています。この 2 つの使い分けが分かれば、あとは並べるだけです。

## どちらになるかは「流れ続けるか」で決まる

| | カラム | ウィンドウ |
|---|---|---|
| 置くもの | 流れ続けるもの（タイムライン、通知、チャット、AI） | 今だけ見たいもの（ノート詳細、プロフィール、設定） |
| 出かた | デッキに縦長の領域として並ぶ | 手前に浮かぶ小窓 |
| 閉じたら | プロファイルに保存され、次回も出る | 消える。保存されない |

ノートをクリックすると詳細が**ウィンドウ**で開くのは、それが一時的な閲覧だからです。一方タイムラインは流れ続けるので**カラム**になります。

## カラムを操作する

- **追加** — カラム追加（＋）ボタン、またはコマンドパレット（`Ctrl+K`）から
- **並べ替え** — カラムヘッダーをドラッグ
- **幅を変える** — カラムの境界をドラッグ。幅は記憶される
- **削除** — カラムヘッダーのメニューから

### 別ウィンドウに切り出す

カラムはポップアウトして OS の別ウィンドウにできます。マルチモニターで通知だけサブディスプレイに置く、といった使い方ができます。

さらに **PiP**（常に手前の小窓）にも対応しています。他のアプリを操作しながらタイムラインを流しっぱなしにできます。

## アカウントの割り当て

カラムごとに「どのアカウントで動かすか」を選べます。

- **特定のアカウント** — そのアカウントの視点で表示する（通常のタイムラインなど）
- **すべてのアカウント** — 全アカウントぶんをまとめて 1 本のカラムに表示する

まとめ表示（cross-account）に対応しているのは、**通知・検索・チャット・メンション・ダイレクト・フォローリクエスト**です。複数サーバーを使っていて通知を見落としたくない場合、通知カラムを 1 本だけ「すべてのアカウント」で置くのが楽です。

## カラムの種類

カラム追加のダイアログは 3 つのグループに分かれています。

### アカウント

自分のアカウントに紐づくもの。

タイムライン / 通知 / ドライブ / フォローリクエスト / リスト / アンテナ / お気に入り / クリップ / メンション / ダイレクト / チャット / 実績

### サーバー

サーバー側の情報を見るもの。ログインしていなくても見られるものが多くあります。

サーバー情報 / Misskeyについて / カスタム絵文字 / 広告 / みつける / お知らせ / 検索 / 照会 / チャンネル / ロール / ギャラリー / Misskey Play / ページ / ユーザー / チャート / 連合

### ツール系のカラム

NoteDeck 独自の作業用カラム。Misskey のサーバーとは直接関係しないものも含みます。

| カラム | 何をするか |
|---|---|
| AI | AI と対話する。セッションを切り替えて履歴を残せる |
| メモ | ローカルのメモ。Markdown ファイルとして保存され、Obsidian などからも開ける |
| タスク | やることの管理 |
| スクラッチパッド | 書き捨て用のテキスト領域 |
| テーマ / プラグイン / ウィジェット / スキル / クエリ | 入れたものの一覧と ON/OFF、編集 |
| ストリーム | サーバーとの WebSocket のやり取りをリアルタイムで覗く |
| API コンソール / API ドキュメント | Misskey API を直接叩く・仕様を引く |

「ストリーム」は Misskey の裏側で何が流れているかをそのまま見られるカラムです。挙動が不審なときの切り分けにも、仕組みを学ぶのにも使えます。

## ウィンドウの種類

ウィンドウは自分で「追加」するものではなく、操作に応じて開きます。

- **詳細** — ノート詳細、プロフィール、フォローリスト
- **インスペクタ** — ノートや通知の生データ（Raw JSON）。API キーなどの機密フィールドは自動でマスクされ、必要なときだけ表示できます
- **ツール** — ログイン、各種エディタ、設定

::: tip カラムが多すぎて見切れるとき
横に並べる数を増やすとカラムは細くなります。用途ごとに[プロファイル](/docs/deck/profiles)を分けて切り替えるほうが快適です。
:::
