# ナビバー

画面左端の縦長のバーです。VSCode のアクティビティバーと同じ発想で、**カラムのトグルボタン**が並んでいます。

## トグルとして動く

ボタンを押すと、対応するカラムがデッキの左端に開きます。もう一度押すと閉じます。開くのは常に 1 つだけで、別のボタンを押すと入れ替わります。

「ちょっと通知を見たい」「メモを開きたい」といったとき、カラムを常設せずに一時的に呼び出せます。常に見ていたいものは、通常のカラムとして並べてください。

## ボタンを入れ替える

ナビバーに何を並べるかはカスタマイズできます。設定のナビバー項目から、ボタンの追加・削除・並べ替え、区切り線の挿入ができます。

アカウントを指定したボタンも作れます。「misskey.io の通知」と「別サーバーの通知」を別々のボタンとして置く、といった構成が可能です。

## プロファイルとは独立

ナビバーの構成は `navbar.json5` に保存され、[プロファイル](/docs/deck/profiles)とは独立して扱われます。プロファイルを切り替えてもナビバーは変わりません。

::: tip 折りたたみ
ナビバーの幅はドラッグで変えられます。細くしていくとアイコンだけの表示に切り替わります。
:::
