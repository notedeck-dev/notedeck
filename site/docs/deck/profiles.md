# プロファイル

プロファイルは**カラムの並び方をまるごと保存したもの**です。用途ごとに作っておき、ワンクリックで切り替えます。

「プロフィール」（ユーザー情報）とは別物です。NoteDeck では、アプリの機能としてのものを**プロファイル**、Misskey のユーザー情報を**プロフィール**と呼び分けています。

## 使いどころ

- **ふだん用** — ホーム、通知、メッセージ
- **イベント用** — 特定のチャンネルとハッシュタグ検索を並べる
- **作業用** — AI、メモ、クライアント検索

見たいものが場面で変わるとき、そのたびにカラムを足し引きせずに済みます。

## 切り替えと管理

プロファイルメニュー（単キー `g`）の一覧から選ぶだけで、デッキ全体が入れ替わります。`Alt+1`〜`Alt+9` で直接切り替えることも、[`notedeck://profile/<名前>`](/docs/guide/links) のリンクから切り替えることもできます。新規作成と削除も同じメニューから、名前などの編集はプロファイルエディタで行います。

保存されるのは「どのカラムをどの順で、どの幅で並べるか」と、切り出した OS ウィンドウの位置と大きさです。[ナビバー](/docs/deck/navbar)のボタン構成はプロファイルとは独立していて、切り替えても変わりません。アカウント情報そのものはプロファイルに紐づきません。どのプロファイルでも、追加済みのアカウントはすべて使えます。

初回起動時は既定のカラム構成のプロファイルから始まります。

## ウィンドウとの関係

プロファイルとウィンドウは別の軸です。

- **プロファイル** = カラム構成の持ち主
- **ウィンドウ** = それを映す先

同じプロファイルを複数のウィンドウで開けます。片方でカラムを足すと、そのプロファイルを開いている全ウィンドウに反映されます。ウィンドウを閉じてもプロファイルの中身は変わりません。
