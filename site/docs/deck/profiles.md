# プロファイル

プロファイルは**カラムの並び方をまるごと保存したもの**です。用途ごとに作っておき、ワンクリックで切り替えます。

「プロフィール」（ユーザー情報）とは別物です。NoteDeck では、アプリの機能としてのものを**プロファイル**、Misskey のユーザー情報を**プロフィール**と呼び分けています。

## 使いどころ

- **ふだん用** — ホーム、通知、チャット
- **イベント用** — 特定のチャンネルとハッシュタグ検索を並べる
- **作業用** — AI、メモ、スクラッチパッド、ストリーム

見たいものが場面で変わるとき、そのたびにカラムを足し引きせずに済みます。

## 切り替えと管理

プロファイルの一覧から選ぶだけで、デッキ全体が入れ替わります。作成・複製・削除・並べ替えもそこから行います。

保存されるのは「どのカラムをどの順で、どの幅で並べるか」と、ナビバーのボタン構成です。アカウント情報そのものはプロファイルに紐づきません。どのプロファイルでも、追加済みのアカウントはすべて使えます。

## ウィンドウとの関係

プロファイルとウィンドウは別の軸です。

- **プロファイル** = カラム構成の持ち主
- **ウィンドウ** = それを映す先

同じプロファイルを複数のウィンドウで開けます。片方でカラムを足すと、そのプロファイルを開いている全ウィンドウに反映されます。ウィンドウを閉じてもプロファイルの中身は変わりません。
