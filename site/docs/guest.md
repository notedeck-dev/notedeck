# ログインせずに試す

アカウント登録もメールアドレスも無しで、サーバーの公開コンテンツを眺められます。まず使い勝手を確かめたいときや、ログインせずに他のサーバーを覗きたいときに使ってください。

## ゲストを追加する

ログインウィンドウで、サーバーのホスト名を入れたあと「**ゲストとして閲覧**」を選びます。認証は発生せず、そのサーバーの公開 API だけを使うアカウントとして追加されます。

複数のサーバーのゲストを同時に持てます。ログイン済みのアカウントと混在させても構いません。

## できること・できないこと

::: tip できること

- 公開タイムライン（ローカル・グローバルなど）の閲覧
- チャンネル・ギャラリー・ページなど公開コンテンツの閲覧
- サーバー情報・カスタム絵文字・連合チャートの観察
- テーマやウィジェットなどローカルのツール

:::

::: warning できないこと

- 投稿・リアクション・フォロー
- 通知の受信
- ドライブ・リスト・アンテナ・クリップの操作

:::

使えないカラムはカラム追加の一覧でその旨が表示され、選べないようになっています。

見られる範囲は各サーバーの公開設定次第です。ログインしていないユーザーに何も見せない設定のサーバーでは、ゲストでは何も表示されません。

## やめるとき

ゲストアカウントを削除するだけです。アカウントメニューから「**ゲストを削除**」を選んでください。サーバー側には何も残りません。

そのまま本ログインしたくなったら、通常どおり[アカウントを追加](/docs/first-run#_1-アカウントを追加する)してください。ゲストとログイン済みアカウントは別扱いなので、ゲストを消してから入れ直す必要はありません。
