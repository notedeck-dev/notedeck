# 設定を Git や Dropbox で持ち運ぶ

NoteDeck の設定は、アプリデータフォルダの中の **`config/`** にまとまっています。この 1 つのフォルダが「持ち運ぶ単位」です。Git で履歴を残しても、Dropbox などで別の PC と揃えても、dotfiles マネージャで管理しても構いません。

`config/` の外にあるもの（ノートのキャッシュ、AI の会話、ウィンドウの位置、同意や鍵の有無）は持ち運ぶものではなく、同期の対象にしないでください。何がどこにあるかは[設定ファイル](/docs/config/files#設定はどこにあるか)にあります。

::: warning 公開はしないでください
`config/` には、どのアカウントをどのカラムで見ているか（`user@host`）、外部サービスの URL、実行されるコード（プラグイン / ウィジェット / スキル）、AI やプラグインに許可している操作が入っています。API キーやアクセストークンは入っていませんが、**公開リポジトリに置くための形ではありません**。Git に入れるならプライベートリポジトリに。
:::

## 前提

- **アプリと常駐の AI を終了してから、外で書き換える。** `git pull` や外部エディタでの編集、同期ソフトによる書き戻しは、アプリを閉じている間に済ませてください。アプリは設定ファイルの外部変更を見張っていないので、開いたまま書き換えると、次の操作でアプリ側の写しが上書きして変更が消えます。常駐の AI（notemaid）が動いていれば `ai.json5` を書き戻すことがあるので、それも止めます。
- **再保存するとコメントは消えます。** 設定ファイルは JSON5 なのでコメントを書けますが、アプリが保存し直すとコメントは残りません。
- **書き込みは決定的です。** 同じ内容なら同じバイト列になり、起動しただけ・読んだだけではファイルを書き直しません。Git の差分が「触っていないのに増える」ことはありません。

## Git で管理する

```bash
cd ~/.local/share/com.notedeck.desktop/config   # macOS / Windows の場所は「設定ファイル」を参照
git init
git add .
git commit -m "NoteDeck の設定"
```

`.gitignore` は NoteDeck が（無ければ）置きます。`config/` の中は設定だけなので、除外するのは書き込み途中の一時ファイルだけです。

### 別の PC で使う

1. 新しい PC で NoteDeck を一度起動して終了します（アプリデータフォルダができます）。
2. `config/` の中身を消して、そこにリポジトリを clone します（または clone したフォルダを `config` という名前で置きます）。
3. NoteDeck を起動し、同じアカウントでログインします。

カラムは `user@host` でアカウントを指しているので、ログインした時点でその PC のアカウントに結び直されます。まだログインしていないアカウントのカラムは「アカウント未接続」として残り、ログインすると繋がります。

外部サービスへの接続（AI のプロバイダーなど）は**定義だけ**が持ち運ばれます。API キーと「AI に見せる / 外部アプリに見せる」の同意はその PC の状態なので、使おうとした時に設定画面が求めます。

### dotfiles マネージャ

- **chezmoi** のようにファイルを**コピー**して配置するものはそのまま使えます。
- **GNU stow** のようにファイル単位で**シンボリックリンク**を張るものも使えます。NoteDeck はリンクを設定として読み、保存はリンクの向き先に書きます（リンクを実体に置き換えません）。

## Dropbox などの同期フォルダに置く

`config/` 全体、または `config/profiles/` のような一部を、同期フォルダに移してシンボリックリンクで元の場所に戻します。

```bash
# 例: プロファイルだけを Dropbox に
mv ~/.local/share/com.notedeck.desktop/config/profiles ~/Dropbox/notedeck-profiles
ln -s ~/Dropbox/notedeck-profiles ~/.local/share/com.notedeck.desktop/config/profiles
```

- **書く PC は 1 台ずつ。** 2 台で同時に NoteDeck を開いて同じフォルダに書くと、後から書いた方が勝ちます。同期ソフトが「競合コピー」を作った場合、同じ id を持つファイルが 2 つになるので、NoteDeck は後に並ぶ方を読み飛ばしてトーストで知らせます。どちらを残すか決めて、もう一方を消してください。
- **`data/`（AI の会話とメモ）は同期フォルダに向けないでください。** 他の人の投稿本文（フォロワー限定や DM を含む）、未投稿の下書き、AI があなたについて覚えたことが入っています。暗号化されないクラウドに置くものではありません。
- **`state/` `cache/` `notecli.db` は同期しないでください。** この PC の状態とキャッシュです。`notecli.db` は SQLite で、書き込み途中を同期すると壊れます。

## 古いバージョンから更新したとき

以前は設定が `notedeck/` というフォルダにありました。更新後の最初の起動で、NoteDeck が `config/` `data/` `state/` `cache/` に分けます。移す前の内容はアプリデータフォルダの `backups/pre-layout-<日時>/` に写しておきます（しばらくすると消えます）。

`notedeck/` 自体をシンボリックリンクにして同期していた場合、NoteDeck は中身を引き抜きません（同期先から消えて、古いバージョンのまま使っている別の PC の設定まで消えるため）。起動時にその旨のお知らせが出るので、同期先の中を `config` と `data` に分けてから、`config/` と `data/` へのリンクを張り直して再起動してください。
