# バックアップ

## 何を守りたいか

NoteDeck が持っているデータは 2 つに分かれます。

| | 中身 | どこ |
|---|---|---|
| **設定** | カラム構成、テーマ、キーバインド、プラグイン、メモなど | [設定フォルダ](/docs/config/files#設定はどこにあるか) |
| **ノートのキャッシュ** | 流れてきたノートの蓄積、アカウント情報 | `notecli.db` |

## 設定のバックアップ

設定はエクスポート / インポートに対応しています。書き出したファイルを別のマシンで読み込めば、同じ環境を再現できます。

対象は[設定ファイル](/docs/config/files#何がどこに書かれるか)に挙げたファイルとフォルダです。**API キーやアクセストークンは含まれません**（OS のキーチェーンにあるため）。移行先では改めてログインが必要です。

## ノートのバックアップ

`notecli.db` を**コピーするだけ**です。SQLite のファイルなので、それ 1 つで蓄積したノートも、アカウント情報も丸ごと入っています。

アプリを終了してからコピーしてください。起動中にコピーすると、書き込みの途中の状態を掴むことがあります。

::: warning 消したら戻りません
アプリをアンインストールしても設定とキャッシュは残りますが、設定フォルダごと削除すると蓄積したノートも消えます。サーバー側から取り直せるのは、サーバーにまだ残っているものだけです。
:::

## Misskey 側のデータ

自分の投稿・フォロー・お気に入りといった、サーバーに預けてあるデータのバックアップは Misskey 側の機能です。サーバーの設定画面からエクスポートしてください。NoteDeck のバックアップはあくまで「この端末の状態」を保存するものです。
