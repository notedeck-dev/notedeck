# 設定ファイル

NoteDeck の設定はすべてファイルとして手元にあります。UI から変更できるものは、そのままファイルにも書き出されます。外部エディタで直接編集しても構いません。

形式は **JSON5** です。コメントを書けて、末尾のカンマも許されます（アプリが保存し直すとコメントは消えます）。

例外として、今開いているプロファイル、ウィジェットの配置、プラグインやウィジェットが `Mk:save` で残した値は、ファイルではなくアプリ内の保存領域にあります。

## 設定はどこにあるか

**ファイル → 設定フォルダを開く** でエクスプローラー / Finder が開きます。これが確実です。

パスを知りたい場合は、OS のアプリケーションデータ領域の下です。

| OS | アプリデータフォルダ |
|---|---|
| Windows | `%APPDATA%\com.notedeck.desktop\` |
| macOS | `~/Library/Application Support/com.notedeck.desktop/` |
| Linux | `~/.local/share/com.notedeck.desktop/` |

環境変数 `NOTEDECK_APP_DIR` でアプリデータフォルダの場所を変えられます。同じメニューから、ログフォルダ・ダウンロードフォルダ・バックアップフォルダも開けます。

アプリデータフォルダの中は、扱いの違いで 4 つに分かれています。

| フォルダ | 何か | 持ち運び / 同期 |
|---|---|---|
| `config/` | **設定。** カラム構成、テーマ、キーバインド、プラグイン、AI の接続先など | できる（[Git や Dropbox で持ち運ぶ](/docs/config/sync)） |
| `data/` | **あなたの記録。** メモ、AI の会話、AI の人格と記憶 | 他の人の投稿本文を含むので、同期は勧めない |
| `state/` | **この PC の状態。** ウィンドウの位置、ズーム、同意や鍵の有無、確認スキップの記憶、編集履歴 | しない |
| `cache/` | **消してよいもの。** 画像、絵文字、ペットのスプライト | しない |

このほか、ノートのキャッシュとアカウント情報の `notecli.db`（SQLite。同期しない）、AI の別プロセスのログ `logs/`、古いバージョンから更新したときの退避 `backups/` が直下にあります。

::: tip 以前のバージョンから更新した場合
以前は `notedeck/` というフォルダに設定・記録・状態が同居していました。更新後の最初の起動で上の形に移され、移す前の内容は `backups/pre-layout-<日時>/` に写しが残ります。
:::

## `config/` に何があるか

| ファイル | 中身 |
|---|---|
| `settings.json5` | テーマの選択、モード、ミュート、キャッシュ設定など、単純な値の集約先 |
| `keybinds.json5` | [キーバインド](/docs/guide/keyboard)の上書き |
| `navbar.json5` | [ナビバー](/docs/deck/navbar)のボタン構成 |
| `performance.json5` | 描画まわりの調整値 |
| `postform.json5` | 投稿フォームの設定 |
| `ai.json5` | [AI](/docs/guide/ai) の接続とモデルの選択、HEARTBEAT の設定 |
| `tasks.json5` | タスクカラムで実行するタスクの宣言 |
| `permissions.json5` | プラグインや AI に許可する操作の方針。壊れていると、すべての行を読み取りのみとして起動する |
| `connections.json` | 外部サービスへの接続の定義（URL と認証方式。キー本体と同意は `state/` 側） |
| `locale.json5` | 表示言語 |
| `custom.css` | [見た目の上書き](/docs/guide/appearance#css-で細かく変える) |
| `.gitignore` | Git で管理する人のための雛形。無ければ作られ、あれば触らない |

フォルダとして持つものもあります。

| フォルダ | 中身 |
|---|---|
| `profiles/` | デッキのプロファイル (`*.ndprofile.json5`)。カラムは `user@host` でアカウントを指す |
| `themes/` | テーマ (`*.ndtheme.json5`) |
| `plugins/` `widgets/` `queries/` | コード本体 `*.is` とメタ情報 `*.meta.json5` の組 |
| `skills/` | スキル (`*.md`)。`AGENTS.md` と `HEARTBEAT.md` は予約 |
| `snippets/` | スクラッチパッドのスニペット |

ファイル名は表示名から作った slug（ストア由来なら storeId）で、参照はファイルの中の id で行われます。同じ id を持つファイルが重複すると後のものは読み飛ばされ、トーストで知らされます。

::: tip API キーはここにありません
アクセストークンや AI の API キーは OS のキーチェーンに入っています（Linux で Secret Service が無い環境では暗号化ファイルに退避します）。`config/` をそのまま誰かに渡しても、鍵は含まれません。ただし公開していい内容でもありません（[持ち運ぶときの注意](/docs/config/sync)）。
:::

## `data/` に何があるか

| フォルダ | 中身 |
|---|---|
| `memos/` | メモ (`*.md`)。Markdown がそのまま入っているので、Obsidian の vault として開ける |
| `sessions/` | AI の会話。自分だけが読める権限で保存される |
| `notemaid/` | AI の人格と記憶 |

`notemaid/` は `SOUL.md`（人格）/ `USER.md`（あなたについて覚えていること）/ `MEMORY.md`（覚え書き）の 3 つの Markdown と、初回だけの `BOOTSTRAP.md` です。外部エディタで直接書き換えても次の会話から効きます（AI には「NoteDeck の外で変更された」と伝わります）。エージェント設定の「ペルソナ」「メモリー」からも読み書きでき、`SOUL.md` の本文だけは開発者モードのタブか外部エディタで編集します。`config/skills/` の `AGENTS.md`（ルール）と `HEARTBEAT.md`（巡回の手順）は名前と役割が固定で、消したり改名したりできず、スキルカラムには出ません（エージェント設定から編集します）。バックアップに入るのは 3 つの Markdown だけです。

## `state/` に何があるか

触る必要はありませんが、消しても設定は失われません。

| ファイル | 中身 |
|---|---|
| `ui.json5` | ペットの位置、ズーム、投稿フォームで最後に使った公開範囲 |
| `deck/<プロファイル id>.json5` | ポップアウトしたウィンドウの配置と、カラムの入力途中の内容（検索語など） |
| `connections-meta.json` | 接続ごとの同意（AI / 外部アプリに見せる）、鍵が入っているか、最後に使った時刻 |
| `permissions-meta.json5` | 「今後確認しない」の記憶と、前回起動時の権限の写し（外から広がっていたら起動時に知らせる） |
| `client.json5` | この PC だけの構成（[AI の別プロセス](/docs/notemaid)の繋ぎ方） |
| `tutorial.json5` | チュートリアルの達成記録と実績 |
| `theme-dropins.json5` | `themes/` に手で置いたテーマの取り込み記録 |
| `history/` | 設定ファイルの編集前の内容（履歴ウィンドウが読む） |
| `notemaid/` `secrets/` | AI の別プロセスの作業状態と、外部アプリ用トークンの記録 |

## アプリの中から編集する

外部エディタを使わなくても、設定エディタのウィンドウから編集できます。[開発者モード](/docs/#開発者モード)では、`settings.json5` などを生のまま編集するタブも出ます。

変更は基本的に**再起動なしで反映**されます。外部エディタで書き換えた場合は、アプリを終了している間に行ってください。アプリは外部変更を見張っていないので、開いたまま書き換えると、次の操作でアプリ側の写しが上書きします。

## 書き間違えたとき

JSON5 として壊れているファイルは読み込みに失敗します。その場合、そのファイルの設定は既定値で動きます（`permissions.json5` だけは安全側に倒れ、すべての行が読み取りのみになります）。おかしいと思ったら、該当ファイルを一度削除してください（既定値で作り直されます）。
