# 通知を受け取る

通知は、アプリを開いている間と閉じている間で届き方が違います。

| 状態 | 届き方 |
|---|---|
| **開いている間** | すぐ届きます。サーバーとの常時接続で受け取り、見ていない口座の通知も OS の通知として出ます |
| **閉じている間 (Android)** | 一定時間ごとに確認して出します。省電力中は遅れることがあります |
| **閉じている間 (デスクトップ)** | 届きません。アプリを開いている間だけです |

## 既読になるタイミング

通知は「通知カラムを見たとき」に既読になります。取得しただけ、アプリを開いただけでは既読になりません。本家の Web や他の端末の未読の表示も、通知カラムを見るまで残ります。

通知カラムが見えている間は、その口座の通知は OS の通知にしません (見ている最中はアプリ内の表示で足ります)。ほかのカラムを見ているときや、通知カラムを置いていない口座の通知は OS の通知で知らせます。

## 通知の種類ごとに音や表示を変える (Android)

OS の通知設定に、種類ごとのチャネルが並びます。

- メンション・返信
- リアクション・リノート
- フォロー
- 投稿の通知 (特定のユーザーの投稿)
- アカウント (ログイン検知など)
- その他 (実績、投票の終了)
- メッセージ

音を変える、表示だけにする、特定の種類を止める、といった調整は OS の通知設定で行います。アプリ側に通知の設定画面はありません。どの種類の通知を受け取るかは、Misskey 本家の設定 (通知の受信設定) に従います。

## 通知の権限 (Android)

最初のアカウントを追加した直後に、通知の仕組みの説明と権限の確認が出ます。拒否した後に受け取りたくなったら、ナビバーのアカウントメニューの「OS の通知設定を開く」から許可できます。

## 閉じている間もすぐに受け取りたい

NoteDeck は閉じている間の即時通知には対応していません。すぐに受け取りたい場合は、Misskey 本家の Web をスマートフォンのホーム画面に追加すると、本家の Web Push が届きます。NoteDeck の通知と重複して届くことがあります。
