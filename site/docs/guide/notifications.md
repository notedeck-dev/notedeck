# 通知を受け取る

通知は、アプリを開いている間と閉じている間で届き方が違います。

| 状態 | 届き方 |
|---|---|
| **開いている間** | すぐ届きます。サーバーとの常時接続で受け取り、見ていない口座の通知も OS の通知として出ます |
| **閉じている間 (Android)** | 一定時間ごとに確認して出します。省電力中は遅れることがあります。プッシュ通知アプリを使うとすぐ届きます ([プッシュ通知で受け取る](#プッシュ通知で受け取る-android)) |
| **閉じている間 (デスクトップ)** | 届きません。アプリを開いている間だけです |

## 既読になるタイミング

通知は「通知カラムを見たとき」に既読になります。取得しただけ、アプリを開いただけでは既読になりません。本家の Web や他の端末の未読の表示も、通知カラムを見るまで残ります。

通知カラムが見えている間は、その口座の通知は OS の通知にしません (見ている最中はアプリ内の表示で足ります)。ほかのカラムを見ているときや、通知カラムを置いていない口座の通知は OS の通知で知らせます。

## 通知の種類ごとに音や表示を変える (Android)

OS の通知設定に、種類ごとのチャネルが並びます。

- メンション・返信
- リアクション・リノート
- フォロー
- 投稿の通知 (特定のユーザーの投稿)
- アカウント (ログイン検知など)
- その他 (実績、投票の終了)
- メッセージ

音を変える、表示だけにする、特定の種類を止める、といった調整は OS の通知設定で行います。アプリ側に通知の設定画面はありません。どの種類の通知を受け取るかは、Misskey 本家の設定 (通知の受信設定) に従います。

## 通知の権限 (Android)

最初のアカウントを追加した直後に、通知の仕組みの説明と権限の確認が出ます。拒否した後に受け取りたくなったら、ナビバーのアカウントメニューの「OS の通知設定を開く」から許可できます。

## プッシュ通知で受け取る (Android)

プッシュ通知アプリ (UnifiedPush 対応のアプリ。ntfy など) を入れると、閉じている間の通知がすぐ届くようになります。使うかどうかはアカウントごとに選べます。使わなくても、閉じている間は定期的に確認して知らせます。

Misskey の仕組みにより、プッシュ通知の登録はアプリだけでは済みません。アカウントごとに 1 回だけ、そのサーバーの Web UI のスクラッチパッドでコードを実行します。同じサーバーのアカウントは 1 つのコードでまとめて登録できます。

1. ナビバーのアカウントメニューから「プッシュ通知」を開き、「有効にする」を押します。プッシュ通知アプリが入っていなければ、入手先を開くボタンが出ます。複数入っている場合は、使うアプリを選ぶ画面が出ます
2. 「コピーしてスクラッチパッドを開く」を押します
3. 開いたブラウザーで、登録するアカウントでログインしていることを確かめます。スクラッチパッドの中身をすべて選んでコードを貼り付け (空なら長押しで貼り付け)、コードのすぐ下の ▶ を押します
4. 「有効にしました」と出たら、ブラウザーでの操作は終わりです。数分以内に「プッシュ通知が届くようになりました」という通知が届きます。同じサーバーのほかのアカウントは、ブラウザーで切り替えてから同じように ▶ を押します

- NoteDeck に戻って何かを貼り付ける手順はありません。最初のプッシュ通知が届いた時点で有効になります。届くまで画面を閉じていてかまいません
- 届く速さはプッシュ通知アプリとその配送サーバーで決まります。サーバーで Web Push が設定されていないと使えません。プッシュ通知アプリのサーバーが自分で立てたものや家の中だけのネットワークにあると、Misskey のサーバーから届かないことがあります
- プッシュ通知アプリやサーバーの登録が変わったり、プッシュ通知で届いていないようだったりすると、アプリの通知に「登録し直してください」と出ます。押すと同じ画面が開くので、もう一度「有効にする」を押します
- 途中からやり直したいときは、その行の「やり直す」を押します。使うのをやめるときは「オフにする」を押します。アカウントを削除したりログアウトしたりするときも解除します
- 登録の情報 (プッシュ通知の送り先と鍵) は端末の中に置き、バックアップには含めません。スクラッチパッドに渡すため、そのアカウントの Misskey のレジストリ (NoteDeck の領域。ほかのアプリからは読めず、本人の Web UI からは見えます) にも一時的に置き、登録が済んだとき・やり直したとき・やめたときに消します

### スクラッチパッドで実行するコード

コードは送り先も鍵も含みません。毎回変わるのは合言葉 (推測できない文字列) と対象のアカウントの一覧だけです。コードは NoteDeck がレジストリに書いた登録待ちを合言葉で探し、それがちょうど 1 件で、ほかに済みや取り消しの印が無いときだけ登録します。ほかのアプリが紛れ込ませた登録待ちでは進みません。古いコードを実行しても、出力欄に 1 行出るだけで何も変えません。

コードの全文は[リポジトリ](https://github.com/notedeck-dev/notedeck/blob/main/crates/notecore/tests/fixtures/push_register_code.is)で読めます (合言葉と一覧は見本の値です)。

## 本家の Web Push を使う

プッシュ通知アプリを使わずにすぐ受け取りたい場合は、Misskey 本家の Web をスマートフォンのホーム画面に追加すると、本家の Web Push が届きます。NoteDeck の通知と重複して届くことがあります。
