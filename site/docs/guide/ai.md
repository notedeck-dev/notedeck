# AI と使う

NoteDeck は AI を組み込めますが、**使うかどうかは任意**です。AI プロバイダの API キーを繋ぐか、手元の CLI を AI にしたときだけ有効になり、繋がなくても他の機能はすべて使えます。

アプリ側で AI の利用料を負担する仕組みはありません。料金は契約したプロバイダから直接請求されます。

AI の本体（エージェントループと HEARTBEAT）はアプリとは別のプロセスで動きます。ふだん意識する必要はありませんが、仕組みは [AI の別プロセス](/docs/notemaid) を参照してください。

## 繋ぐ

1. 設定メニューの**接続**で、プロバイダの API キーを登録する
2. 設定メニューの**エージェント**で、登録した接続を選ぶ

Anthropic、OpenAI、xAI、Google、OpenRouter、OpenCode Go はテンプレートを内蔵しているので、選んで API キーを貼るだけで繋がります。

対応しているのは **Anthropic Messages 互換**と **OpenAI Chat Completions 互換**の 2 方式です。テンプレートに無いサービスでも、自前の LLM ゲートウェイなどどちらかの形式を話すなら手で登録して繋げます。

API キーは OS のキーチェーンに保管されます。設定ファイルには書かれず、プラグインや AI 自身から中身を読むことはできません。

### 手元の CLI を AI にする

API キーの代わりに、手元にインストール済みでログイン済みの AI の CLI（Claude Agent (Claude Code) / Codex / OpenCode / Hermes Agent / Grok Build）をそのまま AI として使えます。接続で「手元の CLI」を選ぶと、見つかった CLI が出ます。

- CLI からの許可要求は、チャットの確認ダイアログとして出ます。権限は「AI チャット」の行で決まります
- 「あなたについて覚えていること」は既定で CLI にも渡します。渡したくなければ「メモリー」の「手元の CLI にも渡す」を切ります（CLI の提供元に送られ、CLI 自身の記憶に残ることがあります）
- HEARTBEAT はこの経路では動きません

## できること

AI カラムで対話するほか、ノートのメニューから直接 AI に投げられます（要約する、翻訳する、など）。

AI はアプリの操作もできます。カラムを足す、アカウントを切り替える、テーマを作る、キーバインドを変える — 会話の中で頼めます。AI が操作した場所は画面上で光るので、何が起きたか分かります。

投稿・リアクションなど**外に影響する操作の前には必ず確認ダイアログが出ます**。勝手に投稿されることはありません。

## 何を見せるか決める

AI に渡す情報は設定で選べます。

- 今使っているアカウント
- 開いているカラム
- 画面に見えているノート
- 会話の履歴

必要ないものは切っておけます。

メモは常時渡しません。AI が持ち越す記憶は「メモリー」(下記) にあり、個々のメモは必要なときに AI が検索して読みます。

## 人格と記憶

AI には、キャラクターを切り替えても変わらない**人格**と、2 種類の記憶があります。エージェント設定の「ペルソナ」と「メモリー」で、いつでも読めます。

- **人格**（ペルソナ）: 価値観や境界、口調の核。AI は自分で書き換えず、提案して承認を待ちます。本文を直接編集するのは開発者モードのタブか外部エディタからです
- **あなたについて覚えていること**（メモリー）: 呼び方や話し方の好みなど、会話であなたが伝えたこと。行ごとに直したり消したりできます。「あなたのことを覚える」をオフにすると、渡さず、新しく覚えもしません (「すべて忘れる」は別の操作です)
- **覚え書き**（メモリー）: AI 自身が拾った小さな事実や決めたこと。行ごとに直したり消したりできます

AI の振る舞いの指針は、同じ画面の「ルール」に書きます。口調や役柄は[スキル](/docs/dev/skill)の「キャラクター」で着せ替えられ、人格はスキルを切り替えても残ります。

初めて AI カラムを開いたときは「呼び方を教える」から始められます。AI が自分の名前と雰囲気をあなたと決め、呼び方だけ聞きます。頼まなければ聞いてきません。

記憶を書くときは、他人の投稿を読んだ直後なら必ず確認が出ます。確認には、どの投稿を読んだかと、書こうとした文が他人の投稿にそのまま出ていないかが添えられます。人格への提案は毎回承認が要り、省略できません。留守番 (HEARTBEAT) の間は記憶に書きません。

## 権限

AI ができることは権限設定で制御します。既定は控えめで、読み取り中心です。

権限は用途ごとに独立しています。チャットでの AI と、後述の HEARTBEAT で動く AI は別々に設定でき、片方を緩めてももう片方には波及しません。プラグインと外部アプリの行も同じ画面にあります。

## 留守中に動かす（HEARTBEAT）

定期的に AI を走らせる仕組みです。「新しい通知に何か重要なものがあれば教えて」といった見張りをさせられます。エージェント設定の HEARTBEAT で有効にし、「巡回の手順を編集」で何をするかを書きます。

- 何も報告することが無ければ黙っています
- 結果は指定したセッションに溜まります。AI が「通知して」とした報告、確認待ちの操作、自動停止は**アプリの通知**（受信トレイ）にも残り、押すと該当の画面が開きます
- 「まず軽く確認」をオンにすると、前回から変化が無いあいだは AI を呼ばずに済ませます
- 1 日の AI 起動回数に上限を付けられ、上限に達すると自動で止まります
- 連続して失敗すると自動で止まり、警告が出ます（気づかないまま壊れ続けないように）

基本はアプリが起動している間だけ動きます。「アプリを終了しても続ける」をオンにすると [AI の別プロセスが常駐](/docs/notemaid#常駐にする)し、閉じている間の報告は次にアプリを開いたときに 1 件にまとめて届きます。

無人で動くぶん、権限はチャットとは別枠で、既定はより厳しくなっています。無人のあいだは記憶に書き込まず、確認が要る操作は実行せずに「あとで確認してから実行」のカードとして報告先のセッションに残します。

::: warning 走らせっぱなしのコストに注意
HEARTBEAT は定期的に API を呼びます。間隔と権限を決めてから有効にしてください。接続ごとに 1 日の token 予算も設定できます。
:::

## 外部の AI エージェントから使う（MCP）

向きを逆にして、Claude Code や Claude Desktop のような外部の AI エージェントに NoteDeck を道具として使わせることもできます。NoteDeck は MCP（Model Context Protocol）サーバーを内蔵していて、ノートの検索や投稿など、AI チャットと同じ capability を tool として渡します。

1. 設定 → 権限 → 「永続 API トークン」でトークンを発行します。発行直後の画面に、Claude Code 用の登録コマンドと、Claude Desktop 用の設定 JSON が出るのでコピーします
2. 外部から使える範囲は、同じ画面の「外部アプリ」の権限で決めます。既定は読み取りだけで、投稿などの書き込みは個別に許可します
3. 書き込みは必ず NoteDeck の画面で確認してから実行されます。外部の AI が勝手に投稿することはありません

Claude Code のように HTTP で繋ぐアプリは `http://127.0.0.1:19820/mcp` に直接繋ぎます。Claude Desktop や Cline のように stdio で起動するアプリには、同梱の `notemaid` を `notemaid mcp` として渡すと、起動中の NoteDeck に転送します。どちらも NoteDeck が起動している間だけ使えます。
