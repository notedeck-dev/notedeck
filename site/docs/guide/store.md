# ストアで拡張する

[misstore](https://store.notedeck.io) から、他の人が作ったものをワンクリックで入れられます。カラムから直接開けます。

## 入れられるもの

| 種類 | 何をするか |
|---|---|
| **テーマ** | 配色を変える |
| **プラグイン** | 機能を足す。ノートメニューの項目追加、投稿の加工など |
| **ウィジェット** | 小さな表示部品 |
| **クエリ** | [カラムの視界を絞る条件](/docs/guide/search#カラムごとに視界を絞る) |
| **スキル** | AI に覚えさせる手順書 |

プラグインとウィジェットは Misskey と同じ **AiScript** で書かれています。本家の Misskey で動くプラグインの考え方がそのまま通じます。

## 有効・無効を切り替える

入れたものは、それぞれ専用のカラム（テーマ / プラグイン / ウィジェット / スキル / クエリ）で一覧・管理します。

プラグインは**アカウントごとに ON/OFF** できます。特定のサーバーでだけ使いたいプラグインを、他のアカウントに影響させずに有効化できます。

## 自分で書く

エディタとライブプレビューが内蔵されています。書いたものはその場で動きます。ストアに出さずに手元だけで使っても構いません。

AiScript で `Nd:register_command` を使ってコマンドを登録すると、そのコマンドは以下すべてから呼べるようになります。

- コマンドパレット
- キーバインド
- AI のツール（AI に「これ使って」と頼める）
- ローカル API（外部アプリや CLI から）

つまり一度書けば、どの入口からでも使えます。

## 安全のしくみ

プラグインやウィジェットができることは、権限で制限されています。投稿やアカウント操作など影響の大きい操作には確認ダイアログが出ます。

信頼できない配布物を入れる前に、何を要求しているかを確認してください。権限の設定は[設定ファイル](/docs/config/files)の `permissions.json5` で管理され、プラグイン側からは書き換えられません。
