# 見た目を変える

## テーマ

Misskey のテーマがそのまま使えます。本家で配布されているテーマコードを読み込めるほか、[ストア](/docs/guide/store)から入れることも、自分で作ることもできます。

ライト / ダークは OS の設定に追従します。手動で固定することもできます（単キー `d` で切り替え）。

アプリ全体のテーマはひとつですが、カラムには**そのアカウントが Misskey 側で選んでいるテーマ**（無ければサーバーの既定テーマ）を映せます。サーバーごとに色が変わるので、どのアカウントで操作しているかが一目で分かります。

## デッキの壁紙

デッキの背景に画像を設定できます。カラムの隙間から見える部分に効きます。

## ペット

デッキにペットを置けます。[petdex.dev](https://petdex.dev) の slug か URL を見た目の設定の「ペット」に入れると現れ、大きさを変えられます。AI の活動に合わせて動きます。

## 画面の大きさ

`Ctrl++` / `Ctrl+-` で画面全体を拡大・縮小し、`Ctrl+0` で戻せます。ノートの本文を「にゃ化」する設定もここにあります。

## CSS で細かく変える

テーマで届かないところは、`custom.css` に直接 CSS を書いて調整できます。ファイルの場所は[設定ファイル](/docs/config/files)を参照してください。

ノートの要素には、判別用の属性が付いています。たとえば自分の投稿と他人の投稿を別の見た目にする、公開範囲によって色を変える、といったことが CSS だけでできます。

::: warning アップデートで壊れることがあります
`custom.css` は内部の構造に直接触れるため、アプリの更新で効かなくなることがあります。壊れて表示がおかしくなったときは、まず `custom.css` を空にして切り分けてください。編集には履歴が残ります。
:::

## 表示の軽さを選ぶ

端末に合わせて、描画の重さをひとつのスライダーで「省メモリ」から「高性能」まで動かせます。「電源・回線・ウィンドウの状態に合わせて自動調整する」をオンにすると、バッテリー駆動や省電力モードでは画像の先読みとアニメーション絵文字を止め、従量制回線では画像・動画をタップで読み込み、ウィンドウを隠している間はタイムラインの購読を休止します。

細かい数値まで詰めたい場合は `performance.json5` を直接編集できます（生のまま編集するタブは[開発者モード](/docs/#開発者モード)で出ます）。
