# 見た目を変える

## テーマ

Misskey のテーマがそのまま使えます。本家で配布されているテーマコードを読み込めるほか、[ストア](/docs/guide/store)から入れることも、自分で作ることもできます。

ライト / ダークは OS の設定に追従します。手動で固定することもできます。

テーマは**アカウントごとに紐づきます**。サーバーごとに色を変えておくと、どのアカウントで操作しているかが一目で分かります。適用範囲は[プロファイル](/docs/deck/profiles)の切り替えに従います。

## デッキの壁紙

デッキの背景に画像を設定できます。カラムの隙間から見える部分に効きます。

## CSS で細かく変える

テーマで届かないところは、`custom.css` に直接 CSS を書いて調整できます。ファイルの場所は[設定ファイル](/docs/config/files)を参照してください。

ノートの要素には、判別用の属性が付いています。たとえば自分の投稿と他人の投稿を別の見た目にする、公開範囲によって色を変える、といったことが CSS だけでできます。

::: warning アップデートで壊れることがあります
`custom.css` は内部の構造に直接触れるため、アプリの更新で効かなくなることがあります。壊れて表示がおかしくなったときは、まず `custom.css` を空にして切り分けてください。
:::

## 表示の軽さを選ぶ

端末に合わせて、描画の重さをプリセットで切り替えられます。省メモリ寄りにも、なめらかさ優先にもできます。フレームレートは端末に合わせて自動で調整されます。

細かい数値まで詰めたい場合は `performance.json5` を直接編集できます。
