# キーボード操作

マウスを使わずに操作できることを目標に作られています。迷ったら**コマンドパレット**を開いてください。

## コマンドパレット

`Ctrl+K`（テキスト入力中でなければ `/` や `?` でも可）で開きます。カラムの追加、アカウントの切り替え、設定を開く、投稿する — 主要な操作はここから名前で探して実行できます。

プラグインや自分で書いた AiScript のコマンドも、同じパレットに並びます。

## 主なショートカット

キーは 2 種類に分かれます。**修飾キー付き**はどこでも効き、**単キー**はテキスト入力中には効きません（入力を邪魔しないため）。

| 操作 | 修飾キー付き | 単キー |
|---|---|---|
| コマンドパレット | `Ctrl+K` | `/` `?` |
| 検索 | `Ctrl+Shift+F` | `s` |
| 通知 | — | `i` |
| 投稿する | `Ctrl+Shift+N` | `p` `n` |
| カラムを追加 | `Ctrl+Shift+A` | — |
| サイドバーの開閉 | `Ctrl+\` | — |
| Boss Key（ウィンドウを隠す） | `Ctrl+Shift+B` | — |

`Ctrl+Shift+N`（投稿）と `Ctrl+Shift+B`（Boss Key）は**グローバルホットキー**です。NoteDeck が裏に回っていても、他のアプリを使っている最中でも効きます。

## 自分で割り当てる

キーバインドはすべて変更できます。VSCode の `keybindings.json` と同じ発想で、既定の割り当てをユーザー側で上書きする方式です。設定は `keybinds.json5` に保存されます。

各ショートカットには適用範囲（スコープ）があります。

- `global` — 常に有効。修飾キー付きのものに使う
- `body` — テキスト入力中は無効。単キーに使う

単キーを `global` にすると文章が打てなくなるので、修飾キーの無いキーには `body` を指定してください。

ファイルの場所と編集方法は[設定ファイル](/docs/config/files)を参照してください。
