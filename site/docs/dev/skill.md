# スキル

スキルは AI の振る舞いを決める Markdown の指示書です。役割や口調、どのデータをどう見るか、どんな形式で答えるかを書いておくと、AI が毎回それに従います。

スキルは AI に**読ませる**もので、AI が**実行できる**機能とは別物です。実行できる機能（テーマを適用する、カラムを追加する、といった操作）は capability と呼ばれ、[権限設定](/docs/guide/ai#権限)で許可した範囲だけが使えます。スキルにいくら書いても、許可していない操作は実行されません。

スキルとは別に、AI には [人格と記憶](/docs/guide/ai#人格と記憶)（スキルを切り替えても変わらない核）があります。スキルで着せ替えられるのは、その上に乗る口調や役柄（キャラクター）です。

## 最小構成

Markdown ファイルの先頭に frontmatter を書き、その下に本文を書きます。

```markdown
---
id: my-skill
name: 要約くん
mode: manual
---

あなたは Misskey クライアント NoteDeck の操作補助 AI です。
日本語で簡潔に応答してください。
```

`id` を省くとファイル名が使われます。ほかに `description` / `author` / `version` / `iconUrl` を書けます。

## いつ読まれるか（`mode`）

| mode | いつ AI に渡るか | 向いている用途 |
|---|---|---|
| `always` | すべての会話で常に | アプリ全体の振る舞いの指針 |
| `manual` | スキルカラムで有効にしているあいだ | 人格の切り替え、必要なときだけ出す専門知識 |
| `trigger` | 入力が `triggers` の語を含んだら。一度当たると、そのセッションの間はずっと渡る | 特定の話題のときだけ要る知識 |
| `heartbeat` | 定期実行のたび | 定期的に様子を見て報告する用途 |

`mode: trigger` は `triggers` に語を並べて指定します。照合は大文字小文字を区別しない部分一致です。会話のたびに全部を読ませるとコストがかさむため、専門的な内容ほど `trigger` が向いています。`manual` の有効状態は frontmatter の `active: true` として保存されます。

## 予約スキル

`skills/` には名前と役割が固定の 2 つがあります。改名・削除・mode の変更・無効化はできず、スキルカラムには出ません。エージェント設定から編集します。中身が実質空のあいだは AI に渡されません。

- `AGENTS.md` — ルール。常に渡る（`always` 固定）。エージェント設定の「ルール」
- `HEARTBEAT.md` — 巡回の手順。定期実行のたびに渡る（`heartbeat` 固定）。エージェント設定の HEARTBEAT の「巡回の手順を編集」

## 書き方の原則

**役割と口調を冒頭で固定する** — 何をする AI で、どう答えるかを最初に書きます。

**どのデータを見るか順番を書く** — 画面に見えているノートやアカウント情報は、AI に毎回渡されています。それで足りるものを capability で取り直させると、無駄な往復が増えます。「画面のノートを参照するときはまず渡されているものを見る、全アカウントが要るときだけ一覧を取る」のように書きます。

**応答の形式を厳密に指定する** — 曖昧な指示だと長文が返りがちです。「1 行目は結論を 30 文字以内」「箇条書きは最大 5 項目」のように制約を書くと効きます。

**失敗したときの振る舞いを書く** — データが取れないとき、権限が足りないとき、要求が読み取れないときに何と答えるかを決めておきます。

**capability 名を明示する** — 「テーマを変えて」とだけ書くと、AI が実際には操作せずに「変えました」と答えることがあります。「`themes.list` で一覧を取る → 名前が一致する id を選ぶ → `themes.apply` で適用する」のように手順と名前を書きます。

## 定期実行するスキル

`mode: heartbeat` のスキルは、エージェント設定で HEARTBEAT を有効にしているあいだ、定期的に実行されます（既定は無効）。アプリを起動しているあいだが基本で、[常駐](/docs/notemaid#常駐にする)にすればアプリを終了しても続きます。スリープからの復帰時にも 1 回走ります。

frontmatter の `cheapCheckCapabilities` に「何を見張るか」（通知の一覧など、読み取りだけの cheap な capability）を並べておくと、前回から変化がない間は AI の呼び出し自体が省かれます。宣言しないと、変化がなくても毎回 AI が呼ばれて課金されます。省略が続いても、一定時間ごとには必ず走ります。

実行のたびに必ず変わるもの（現在時刻など）を見張り対象にすると、常に変化ありと判定されて省略が効きません。「何が変わったら起きてほしいか」から選んでください。

HEARTBEAT 中の権限はチャットとは別の行（既定は読み取りのみ）で、1 日の AI 起動回数の上限も設定できます。手元の CLI を AI にしている接続では HEARTBEAT は動きません。

## 機密の扱い

AI に渡されるデータからは、トークンやパスワードにあたる項目が自動で取り除かれます。

## 作る・配る

AI カラムで「〇〇するスキルを作って」と頼めます。手で書く場合は設定フォルダの `skills/` に Markdown を 1 ファイル置くだけです。新規作成と編集の入口は[開発者モード](/docs/#開発者モード)で開放されます。作ったものは [MisStore](https://store.notedeck.io) で配布できます（[提出のしかた](https://github.com/notedeck-dev/misstore/blob/main/CONTRIBUTING.md) / [書式](https://github.com/notedeck-dev/misstore/blob/main/docs/registry-format.md#スキル)）。

capability の一覧と権限の詳細は、リポジトリの [SKILLS.md](https://github.com/notedeck-dev/notedeck/blob/main/SKILLS.md) を参照してください。
