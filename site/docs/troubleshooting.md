# トラブルシューティング

困ったら、まず **NoteDeck について**（About）ウィンドウの「自己診断」を見てください。ストリームの切断、前回の異常終了、AI の別プロセスの状態、HEARTBEAT の連続失敗がまとめて出ます。「情報をコピー」で報告用の情報を取れます。

## ログインできない

サーバーのホスト名を入れます（`misskey.io` の形。`https://` や末尾の `/` は付いていても取り除かれます）。

認証はブラウザ経由です。ブラウザで許可したあと、NoteDeck 側の「認証しました」を押すまで完了しません。既定のブラウザが開かない、途中で分からなくなった、という場合は「やり直す」で最初からやり直してください。

Linux で Secret Service（GNOME Keyring 等）が無い環境では、起動時にその旨の警告が出て、トークンは暗号化ファイルに退避されます。

## タイムラインが更新されなくなった

NoteDeck はサーバーと WebSocket で常時つながっています。回線が切れたりスリープから復帰した直後は、再接続までに少し時間がかかります。

しばらく待っても流れてこない場合:

1. **オフラインモード**やリアルタイムモードが切れていないか確認する（トレイメニューからも切り替えられます）
2. 「ウィンドウを隠している間はタイムラインの購読を休止」の設定が効いていないか確認する
3. カラムを手動で再読み込みする
4. About の自己診断で接続状態を見る。さらに追うなら、[開発者モード](/docs/#開発者モード)で**ストリーム**カラムを開き、流れているイベントを確認する

ストリームカラムには実際のやり取りがそのまま出るので、「サーバーから届いていない」のか「アプリが表示していない」のかを切り分けられます。

## ノートが表示されない・急に消えた

表示されない理由はいくつかあります。

- **ミュートに引っかかっている** — ワード、ユーザー、インスタンス、リノートのミュート設定を確認
- **カラムクエリで絞っている** — カラムのフィルタメニューで、適用中のクエリを確認
- **投稿者が凍結された** — サーバー側で凍結されたユーザーのノートは隠れます。凍結が解除されれば自動的に戻ります

NoteDeck はデータを消さずに「表示するかどうか」だけを判断しています。ミュートを解除すれば、隠れていたノートはそのまま戻ります。

## 画像が出ない・外部連携が使えない

起動時に「画像の中継と外部連携 (HTTP API) を使えません」と出る場合は、NoteDeck が使うローカルのポートを他のアプリが先に取っています。そのアプリを止めるか、ポートを空けてから NoteDeck を起動し直してください。

## 見た目が崩れた

`custom.css` を書いている場合は、まずその中身を空にして確認してください。アプリの更新で内部構造が変わると、以前書いた CSS が意図しない場所に当たることがあります。

テーマが原因のこともあります。既定のテーマに戻して切り分けてください。

## 動作が重い

- 開いているカラムの数を減らす（[プロファイル](/docs/deck/profiles)で用途ごとに分ける）
- [表示の軽さ](/docs/guide/appearance#表示の軽さを選ぶ)を省メモリ寄りのプリセットに変える
- 画像の多いカラムを閉じる

## AI が応答しない

- API キーが有効か、プロバイダ側の残高があるか
- エージェント設定でプロバイダが選択されているか
- 権限で必要な操作が禁止されていないか（確認ダイアログを閉じてしまっていないか）
- AI の別プロセスが動いているか。About の自己診断に、子プロセスの終了・版の不一致・常駐が動いていない、といった理由が出ます。詳しくは [AI の別プロセス](/docs/notemaid#困ったとき)

HEARTBEAT が連続して失敗した場合は自動で停止し、警告が出ます。原因を直してから再度有効にしてください。

## 設定を初期状態に戻したい

該当する[設定ファイル](/docs/config/files)を削除すると、次回起動時に既定値で作り直されます。全部を戻したい場合は設定フォルダごと削除してください。

::: warning
設定フォルダを消すと、メモ・AI の人格と記憶・AI セッション・スキル・プラグイン・テーマも一緒に消えます。先に[バックアップ](/docs/config/backup)を取ってください。蓄積したノート（`notecli.db`）は設定フォルダの親にあるので残ります。
:::

## それでも直らないとき

[GitHub の Issues](https://github.com/notedeck-dev/notedeck/issues) に報告してください。以下があると原因を追いやすくなります。

- OS とアプリのバージョン
- 何をしたら起きるか
- About の自己診断の「情報をコピー」の内容（異常終了のあとは「診断ログをコピーして報告」）
- ログ（**ファイル → ログフォルダを開く**。AI の別プロセスのログはアプリデータフォルダの `logs/`）
